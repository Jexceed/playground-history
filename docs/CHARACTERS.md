# 小小历史旅行团的角色识别约定

2026-09-14依据用户“两个男孩过于相似”的反馈确定。三位都是虚构的现代儿童旅行者，不是历史人物。

| 角色 | 稳定视觉特征 | 网页中的主要识别点 |
| --- | --- | --- |
| 黄衣男孩 | 原来的蓬松翘短发，无眼镜，黄色外套、蓝色背包 | 翘起的头发轮廓与黄色外套 |
| 绿衣男孩 | 深棕圆框眼镜、整齐短发与平齐刘海，绿色外套、紫色背包 | 圆框眼镜与整齐头发轮廓 |
| 红衣女孩 | 原来的高马尾与橙色花发夹，红色外套、黄色背包 | 马尾轮廓与花发夹 |

人物不能仅靠衣服颜色区分。眼镜镜片透明、眼睛和表情清楚，轮廓需要在当前网页上可辨识；不夸张成护目镜。

保留已有动作、人物尺寸、表情和绘本画风。主页、章节相聚画面、结束页及分享图必须同步使用同一版本；只出现黄衣男孩的工坊图沿用原图。
