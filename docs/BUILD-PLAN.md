# 本地建设方案

更新日期：2026-08-08

## 最终目标

先完成并确认一套适合低龄儿童的历史内容与玩法，再把同一套内容包转换为微信小程序。平台转换不是当前完成标准。

产品结构采用三层：

```text
课程与史料层
  Markdown章节 + JSON目录 + 来源/许可登记
            ↓ 生成与校验
平台无关内容包
  91章JSON + 缩略图 + 稳定音频ID
            ↓ 不同界面读取
本机网页版（当前） → 微信小程序（最终确认后）
```

## 阶段与退出条件

### 阶段A：跨平台内容基础——已完成

- 建立七条时间线和91章目录；
- 完成91章第一版事实、儿童、语音和互动稿；
- 建立来源、许可和本地素材登记；
- 生成网页与未来微信端共用的JSON内容包；
- 移除ChatGPT登录依赖。

退出证据：`npm run content:pack`通过，`public/content/manifest.json`数量一致。

### 阶段B：本机试玩与代表章复核——进行中

- 用“隋唐长安”测试低龄首页、时间线、真实文物、五步因果和本地语音；
- 12个代表章完成第一轮人工编辑复核；
- 收集至少一轮5—8岁儿童真实操作与复述记录；
- 根据共性问题回查91章。

退出条件：孩子不经讲解能开始；能复述一条因果链；能分清文物、遗址、艺术表现和故事角色；家长能找到来源与素材说明。

### 阶段C：全库内容确认——待进行

- 按同一规则人工复核其余79章；
- 逐张核对420项可发布素材的题名、年代、来源、许可、标签与显示效果；
- 冻结全部儿童稿、语音稿和稳定ID；
- 将确认章的 `status.review` 改为 `approved`，不得批量提前改状态。

退出条件：91章八项验收全部通过，自动校验继续通过，用户确认冻结内容版本。

### 阶段D：正式语音与全章节玩法——待进行

- 锁定A/B音色组合、语速、停顿和多音字表；
- 生成当前1092段正式本地音频并抽听；
- 根据本机试玩结果建立可复用关卡模板，再逐章游戏化；
- 校验触控、键盘、手机尺寸、断网播放和本机进度。

退出条件：无漏段、错段、异常音量和明显误读；代表玩法通过第二轮儿童测试。

### 阶段E：微信小程序转换——明确暂停

只有用户确认阶段C和D以后才开始。转换时复用内容包、素材和音频，重写平台界面与存档层；不要求ChatGPT登录。第一版可只保存本机学习进度，微信登录、支付和家长体系另行决定。

## 变更门禁

任何内容或资源变更至少运行：

```text
npm run content:validate:assets
npm run content:pack
npm test
npm run lint
git diff --check
```

自动通过只说明结构完整，不证明史实、叙事和儿童理解已经最终通过。
