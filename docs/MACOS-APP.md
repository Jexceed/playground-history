## 实现边界

- 采用与小小思考屋相同的Tauri 2 + 系统WebView，复用现有React游戏和五步进度，不重写题库或新建玩法入口。
- Mac包使用单独的Vite静态入口，包含44章所需图片、JSON与预生成MP3。运行不启动Node服务，不依赖4173端口，也不在启动时下载内容。
- 原网页工具链仅保留作历史开发辅助，未经用户明确要求不启动浏览器诊断，也不作为验收或交付。App与旧浏览器记录分开，家长可导出/导入JSON学习记录；导入合并完成标记，保留兼容的继续位置。
- 本轮面向当前Apple Silicon Mac，初始内容窗口1280×720。不扩展Windows、iOS或多套设备矩阵。
- 史料链接由用户点按后交给系统浏览器，避免外部网页替换游戏窗口。无登录、支付或儿童数据上传。
- 新Logo用于App/Dock图标和游戏品牌入口，保留透明PNG原图、Mac ICNS及生成提示词。2026-10-10用户确认集中构图，底板由浅薄荷改为白色，三位伙伴、地图、时间河和长城呼应主页，去掉厚金边与复杂远景；[当前记录](qa/2026-10-10-logo-white/README.md)，[旧版记录](qa/2026-10-09-logo-refinement/README.md)。
- 清理仅处理已核实的旧临时路径记录与Python字节码，先归档核验再移除；研究原图、历史QA和课程源稿保留。

## 验收

检查Web原有门禁、Mac静态资源完整性、学习记录往返/合并、真实`.app`启动和声音、关闭重开后的续玩、父母导入/导出、无4173服务时运行，以及应用图标。构建成功和实际启动分别记录；本机临时签名不等于Apple开发者签名或公证。

## 构建和文件

- `npm run mac:icon`：从已登记品牌原图导出PNG与ICNS。
- `npm run mac:build`：准备课程资源、构建静态客户端，编译并临时签名Apple Silicon `.app`。
- `npm run mac:install`：重新构建、验签并安装到`/Applications/小小历史旅行团.app`；同名但标识不同的应用拒绝覆盖，同项目旧版先备份。
- `npm run mac:package -- --skip-build`：将最新已构建App制作成ZIP和带Applications快捷方式的DMG，不重新编译。
- `npm run mac:dev`：开发窗口使用明确的内部调试端口1420；仅供显式开发调试，最终验收必须使用打包安装后的App。

产物：`release/小小历史旅行团.app`、`release/little-history-trip-0.1.0-macos-arm64.dmg`和同名ZIP。PNG Logo在`public/images/brand/history-trip-logo.png`，Mac ICNS在`src-tauri/icons/icon.icns`；原图和提示词已在项目内留存。

当前包有44章、11站、2044段游戏声音、2713个资源文件。打包器从当前展示清单自动收集，并验证每条资源；112章源库与旧隐藏章的完成标记索引仍保留在项目中。`desktop-build.json`列明实际客户端运行库，构建失败门禁禁止Next、Vinext、RSC和其他服务器运行库进入Mac包。
