# 结束导航对齐与图标修正

2026-09-14，响应用户对“返回时间河”和“再玩本章”对齐、图标的反馈。

## 原因与修改

原先两个按钮混用不同通用类：primary-action使用flex，内容靠左且阴影9px；secondary-action为居中block，没有阴影。按钮内还使用系统Emoji，在实际显示中出现大小和造型不一致。

新增共享 `app/FinishNavigation.tsx` 与 `app/finish-navigation.css`，统一外框、内容居中、图标列与文字列、行高和4px投影。两个图标改为同样线宽的地图与重玩SVG，桌面24px、手机22px；不再继承首页CTA的特殊span样式。主次颜色和原先导航动作保留。结束相聚图片经过目视检查，沿用原图，没有重新生成或改变裁切。

## 验证

- 801×785：两按钮均312×54，顶边、底边、图标位置、文字容器基线一致，阴影均4px。
- 390×600：两按钮均175×50，默认底边474.4px；展开总结后底边555.4px，仍在屏幕内；页面无横向溢出。
- 实点“再玩本章”回到秦朝封面并显示开始按钮，走完新一轮五步后，再实点“返回时间河”，确认进入主页。
- 已恢复临时窗口尺寸。严格素材检查、构建、20项现有测试、lint、界面类型检查与diff格式检查通过。
- 源题库、声音清单和内容版本文件的SHA-256与修改前一致；未重新生成语音或改动历史材料。共享按钮修正会用于各章结束入口，未重测其他33章完整流程。

本轮问题已补充为DESIGN-IMPROVEMENTS中的UX18，设计方案、实施指南与AGENTS同步要求结束导航复用同一组件。原始备份见baseline.txt，尺寸和结果见verification.json。
