## 实机发现的布局问题

在原1280×690内容区，兵马俑彩绘题的完整材料入口被压到首屏外；错误、正确反馈后仍如此。前进按钮完整可见，但不能因此说全部操作可用。优化前证据为`terracotta-before.jpg`、`terracotta-wrong-before-fix.jpg`、`terracotta-right-before-fix.jpg`。

源码还发现游戏阶段用CSS隐藏了统一家长入口。已恢复该入口，并从共享可用高度中预留页脚空间；找图保留标签和完整材料卡的空间，情境选择页移除重复的泛化提示占位，保留实际问题、声音与具体反馈。原图取景、热点坐标和完成判定没有改变。

全114章结构扫描得到10个“找图＋材料入口”步骤，清单见`supporting-material-scope.json`。恢复家长入口的共享样式影响当前所有游戏阶段，必须在本轮窗口复验材料、情境选择、阅读、尺子与history-lab等题型；当前锁屏前截图不证明新样式已通过。
