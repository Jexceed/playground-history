## 材料与插画

- [UNESCO长城条目](https://whc.unesco.org/en/list/438/)支持秦连接更早墙段、后世继续修筑的主线。只使用这些具体事实，不照搬页面其他泛化说法。
- [固阳县政府的秦长城介绍](https://www.guyang.gov.cn/ywdt/tt/202508/t20250821_261353.html)支持因地制宜的石、土等筑墙材料；不把所有墙段写成一种做法。
- [河北省文物局的金山岭长城介绍](https://wenwu.hebei.gov.cn/system/2023/11/15/030263380.shtml)核对照片对象为明代长城。照片来自[Commons原文件页](https://commons.wikimedia.org/wiki/File:The_Great_Wall_of_China_at_Jinshanling-edit.jpg)，Severin.stalder摄影、Brandmeister调整蓝色饱和度，CC BY-SA 3.0。网页主图采用景物构图，大图层显示全幅。
- 《史记·蒙恬列传》的临洮、辽东等文献线索保留在家长延伸，不能解释成今天全部长城的统一起止。汉代玉门关退出本章证据关联，继续保留原有汉代用途。可靠断代且可复用的秦墙照片仍有缺口。
