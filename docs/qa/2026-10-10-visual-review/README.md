# 2026-10-10 · 整体布局与视觉层级复核

## 范围与问题

用户要求整体布局有统一设计，排布合理、不突兀。沿首页、选站、章节开场、五步游戏、材料查看、结束、家长目录与详情审视。本轮主要处理：

- 单故事历史站仍占用多卡片的大弹层，右侧大片空白；双卡与多卡没有按数量组织。
- 长任务列表的顶部返回会随内容滚出窗口。
- 材料标题、照片身份与声音控件分散，图上说明压住照片。
- 首页顶栏背景出现独立色块，声音图标与页脚位置不一致。
- 家长入口的记录、统计与编辑音色占据大量首屏空间，单板块切换没有实际用途。
- 家长卡片因文案长短不同造成按钮底边错位；详情图文分别居中、标题过大。

源码修改前备份在`work/visual-review-2026-10-10/before/`；本轮开始的App记录在同目录的`progress-before.json`。保护先前导航、布局与Mac改造等未提交工作；品牌图片在独立任务中更新，本轮未编辑品牌素材。

## 统一规则

- 延续1220px主外框、80px顶栏和儿童主流程7:5分栏；24px内边距、32px栏距、16px组间距。
- 地图与普通历史站宽1080px，单故事站880px，材料1180px；统一浅色边线、24px圆角和柔和投影。
- 弹层标题/导航固定在顶部，历史站只滚动正文；换站或返回选择时复位正文位置。
- 1张故事卡为横向图文，2张两列，其余三列；材料身份紧邻图片，行动在卡底。
- 材料标题在独立顶行，照片下方显示身份，重听/暂停同组，来源默认折叠。六图相册复用同一版式。
- 公共声音按钮复用SoundIcon，首页顶栏透出首页背景，儿童页脚家长入口居中。
- 家长记录、统计与音色说明默认折叠，目录可直接搜索/筛选；同排卡片的统计和查看按钮底边一致。
- 家长详情以5:7阅读分栏容纳较多文字，左右从同一顶边开始，标题36px，材料缩图完整显示。

规则已写入AGENTS、设计方案与任务实施指南。未改课程事实、题干、选项、图片源文件、声音台词、chapterId、内容版本或进度格式。
