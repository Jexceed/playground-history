## 来源与文件

- [河北省文物局](https://wenwu.hebei.gov.cn/system/2023/11/15/030263380.shtml)与[UNESCO长城记录](https://whc.unesco.org/en/list/438/)核对明代长城及墙体、通道、城楼等组成关系。
- [敦煌研究院研究人员张小刚的考古综述](https://www.nopss.gov.cn/n1/2023/0828/c219544-40065225.html)支持敦煌汉长城、烽燧、小方盘城等遗存身份与边防交通背景。
- [甘肃省文博局网站刊载的现场报道](https://www.gswbj.gov.cn/a/2023/10/11/18852.html)补充敦煌地区汉长城土料与植物材料分层的实例；不推广为所有长城的统一建法。
- 具体照片的作者、拍摄对象与许可证分别在Commons原文件页核对，网页中逐图提供文件页、许可证和事实来源。完整映射见[验证记录](verification.json)、`content/assets/qin-han-assets.json`和`reference-assets/qin-han/ATTRIBUTION.md`。

原件在`reference-assets/qin-han/`，文件页快照在其`source-pages/`子目录，均属于被Git忽略的研究材料。运行图由现有缩图脚本生成，只做等比例缩小与JPEG压缩，大图完整显示，未裁掉或重画照片。下载使用本机已配置的网络代理，没有更改系统设置；一次限流后间隔重试成功，过程见[下载记录](download-candidates.json)。

## 页面与实现

章节封面和首步有“看看真实的长城”入口；首步照片也能直接打开相册。守关一幕的材料入口明确写出“明代城楼”，直接定位第三张；第五步可再翻整本相册。

复用原图片说明弹层，通过`photoAlbum`配置和`focusAlbumPhoto`把图片、年代、观察提示、完整说明声音、边界及出处一起切换。每张只给一个简短观察点，有缩图直达、前后翻页、重听和暂停，不自动轮播，不要求读完或答对。关闭相册回到原来步骤，不清空已选正确答案，也不增加完成条件。

家长资料默认折叠；展开长说明后从顶部正常滚动，保留可见的年代与标题。没有新建章节入口或完成状态机，也没有改动其他33章的逐题源稿。
