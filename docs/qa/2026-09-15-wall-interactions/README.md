# 长城后半章：从观察到选择

实施日期：2026-09-15—16。用户指出增加相册后，后面几步的问题和互动偏少。本轮改第四、第五步；前三步和六张照片相册逐项比较保持原样，其他33章逐题源稿没有变化。

## 孩子新增的参与

| 步骤 | 提问与操作 | 回应 |
| --- | --- | --- |
| 第四步第一问 | “谁在观察远处的动静？”在故事图中点人 | 点错守门的人会提示再找望远的人；答对后进入下一问 |
| 第四步第二问 | “有人来到关口，谁来查看？”再次在同一张图里找人 | 点错望远的人会提示找门旁的人；两问都完成才进入第五步 |
| 第五步 | “想早点发现远处的动静，先怎么办？”从请守卫望远、请工匠继续修墙中选办法 | 主画面随选择变成守卫或修墙场景；反馈说明及时观察、传递消息的作用 |

两个选项都属于真实的边防工作，但对眼前目标有不同作用。沿用既有的守关与运料插画，从同画风场景裁取图卡，没有调用图片生成工具，也没有用照片混配示意。防御用途继续出现在开场与结束回答中。

## 实现与复用

`scene-find`把归一化热点、目标人物、问题和正误回应写入正式逐题源稿。题内两轮仍属于同一个`change`步骤，中间一问答对不会触发整步完成；全部完成后沿用原来的五步进度与结束逻辑。相册只显示材料，关闭时保留已答状态。

`scene-card`复用已登记故事图和明确裁取范围，选择时更新主场景。裁取范围使用显式裁切路径，避免原图中范围外的旁人露进卡片。两项表现类型一致，图片和声音均由生成包绑定。

第一轮先播放短故事与问题，换轮只播放新问题。多轮题的当前问题/回应按章节与步骤记录，重新开启声音时继续对应当前内容，不回到第一问；进入下一步或重玩时清除旧声音指向。

新增类型同时扩展了入口生成、内容打包、结构审计和现有测试。首次打包发现后段仍有只允许普通选项的旧校验，已补齐；不是放松全库的选项约束。全库仍保持103章、515步，当前可见34章、170步。
