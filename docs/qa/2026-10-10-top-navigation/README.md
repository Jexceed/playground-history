# 2026-10-10 · 顶部返回与五步自由跳转

## 用户目标与实现

用户指出章节正文中的“回到时间河”突兀、进入游戏后没有明确返回入口，顶部阶段只能展示不能选择。本轮将返回统一到顶部，并把五个阶段改成可点击导航。

- `ReturnToRiverButton`用于全局顶部和材料弹层。封面、游戏、结束、家长目录/详情都使用顶部返回；删除正文散放的返回链接，品牌Logo改为静态标识，明确可点的按钮承担返回。家长长页滚动后顶栏仍在原位置。历史站/专题既有顶部返回保留；大图的关闭×返回原步骤，与回首页区别。
- `QuestNavigation`展示1时间、2起点、3旅程、4变化、5发现，全部可直接选择。深绿代表当前，浅绿加勾代表实际完成，不能按步骤序号补记已跳过的步骤。
- 跳转复用共享五步状态与声音：停止旧声音，卸载上一题局部状态，清掉旧反馈和旁白覆盖，播放新步骤完整引导并保存位置。点击当前阶段不会重复重置本题。
- 原schemaVersion 2的current增加可选`completedStepIds`；新记录显式写实际完成列表，旧顺序记录缺少此字段时兼容此前缀。旧chapterId、内容版本0.68.0和整章完成标记保留。同章导入时合并步骤完成列表。
- 实际通过问答/全部操作阶段才记录该步；阅读页点击继续才记录。下一步寻找尚未完成的步骤，全部完成才到结束。跨回前面时按钮写“去第N步”，避免“结束”按钮却返回未完成步骤。

代码：`app/QuestNavigation.tsx`、`app/quest-navigation.css`、`app/page.tsx`、`app/quest-progress.ts`、`app/ObjectWorkbench.tsx`、`app/ContentOverview.tsx`。规则同步AGENTS、设计方案与实施指南；故事、史实、素材、题干和声音未改，无新TTS。
