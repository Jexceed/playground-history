2026-09-15。用户指出上一版大量讲修墙，却没有讲清长城抵御外敌的作用。本轮只调整秦长城主线及其必要的入口、配图、语音和规范，其他33章逐题稿与本轮开始时一致。

## 来源与图片

- [UNESCO长城记录](https://whc.unesco.org/en/list/438/)开头明确秦连接更早防御设施，用于抵御来自北方的进攻；正文说明墙体、关口和瞭望设施等共同组成长城。本轮据此把防御目的放进儿童主线。
- [上海市绿化和市容管理局：亭的历史和用途](https://lhsr.sh.gov.cn/jnylwh/20221008/262a36d4b395419c98a79ff001b8f62e.html)说明亭障、亭候的边防、观察敌情与通报军情功能。只取这一功能说明，不推导特定秦代设施的外观或固定传信规则。
- 既有《史记·蒙恬列传》研究记录保留给家长，提供秦朝北方军事背景与文献线索。长城并非不可越过，也不会自行防御；故事不把所有长城外的人都当作敌人。
