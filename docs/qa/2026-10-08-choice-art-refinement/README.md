单幅采用scene-card，顺序/并立/功能配对采用共享scene-strip。每个分镜登记素材ID、原图取景和短标题；同一道顺序题重复使用同一组图，只改变排列。选择前与选中后共用画面与取景，不增加第二套状态机。分镜选项上下排列以放大每一格，主画面展示同一组图。故事插画与历史材料分别标识；真文物首步、找图与可放大材料入口保持。

精确桥水位、经纬交错、宫灯操作和尺子几何没有改为生成图片。新图册可登记runtimeMaxEdge，避免整张多格图被统一缩到900后局部模糊；仅图册提高导出上限，普通材料保持既有900与压缩设置。

## 素材与提示词

使用**内置image_gen**，没有切换CLI或新增API密钥。10张最终PNG在 `reference-assets/choice-art-refinement/`，逐个路径见 `outputs-final.json`；署名与边界见 [ATTRIBUTION](../../../reference-assets/choice-art-refinement/ATTRIBUTION.md)。运行JPG由既有脚本生成到`public/content/step-images/`。原PNG不进入普通Git。

实际提示词：`prompts.json`、`prompts-batch2.json`、`prompt-revisions.json`、`prompt-jianzhen-retry3.txt`、`prompt-jianzhen-retry4.json`。鉴真早先请求出现网络错误，中断的一次没有落盘结果；恢复后以同一场景的现成JPG作为风格参考完成。网络失败没有用占位图冒充成功，也没有覆盖原素材。

火药初稿把烽火台画成主要线索，已拒用并保存在`inventions-beacon-rejected.png`。修订依据是本章已登记的[晋江市政府《曾公亮和〈武经总要〉》](https://www.jinjiang.gov.cn/yxjj/szjj/wssl/202406/t20240603_3043257.htm)关于火球、火箭类军事记录的说明；最终只作非技术性故事表现，不宣称具体战役、人物肖像或装置精确构造，不画配方、制作或伤亡得分。

先验看每张原图，再核对图册分隔线的位置。`choice-art-map.json`保存实际边界与40个选项的取景，不机械假定所有生成图片都精确等分。图片中的人物、器物和动作供理解本题，错误选项包含假设；这些画面不作为史料。旧图、原故事与真实材料都保留。

`apply-art.py`仅为本轮制作过程记录。最终正式源稿是`content/focused-quests.json`和素材登记，后续修改不要重跑此脚本覆盖编辑。备份位于`/tmp/history-choice-art-before`。
