## 2. 首批建议补强的6章

### 2.1 兵马俑：补“原来有彩绘”，让保护有具体对象

**当前缺口：** 五步已讲清陪葬陶塑、姿态与服饰，但第4、5步主要强调看实物、保护文物，新的历史发现较少。现有5条事实卡也没有彩绘内容。

**核验依据：** 秦始皇帝陵博物院说明，秦俑彩绘包含生漆底层与颜料层；环境湿度改变会使脆弱彩绘起翘、脱落，保护工作有具体技术对象。这里只采用彩绘及保护机制，不沿用报道中的历史游客统计或“第八大奇迹”宣传称号。[馆方彩绘保护研究](https://bmy.com.cn/news/news/2060.html)

**儿童短句候选：** “这些陶人原来还涂着颜色。今天许多颜色已经脱落。研究人员小心保护留下的痕迹，让我们继续了解工匠怎样制作它们。”

**动作与可观察理解：** 取得可用的彩绘残留近照后，比较“今天常见的土色”与“仍留下的颜色”，孩子能指出“现在看到的样子不等于刚做成时的样子”。不让孩子给真文物照片随意上色，不用AI复原图证明具体原色。

**落点：** 新增馆方来源和事实卡；优先替换第4步的泛化判断，并同步收尾与learning-map。彩绘图片尚未选定、授权尚未核对，本轮不将此项标成可直接发布。

### 2.2 司马迁：回答“他怎样知道比自己早的事情”

**当前缺口：** 已会区分孔子、秦始皇、司马迁的先后，也能找人物书签，但题目没有充分回答章名中的“怎样把过去的事留下来”。底稿强调体例与版本，调查、搜集材料的过程仍弱。

**核验依据：** 国博“司马迁与《史记》”条目介绍其阅读史籍、游历、考察风俗与采集传说；国家图书馆说明《史记》为纪传体通史，后来又形成注释与刊印传统。[国博人物条目](https://en.chnmuseum.cn/Portals/0/web/exhibition/exhibitions/161120Chines-Epic/)、[国家古籍保护中心](https://www.nlc.cn/pcab/zx/xw/20200708_192637.shtml)

**儿童短句候选：** “司马迁读过旧书，也到过许多地方，搜集流传下来的故事。他研究这些材料，写下许多不同时代的人和事。”

**动作与可观察理解：** 保留人物先后，补一个“没见过孔子，还能去找什么材料”的情境；孩子能选读已有记录、了解流传故事，并知道这与亲眼见过是两回事。不要将听来的故事自动判为确证，也不要暗示《史记》每一句都没有争议。

**落点：** 第2步先交代搜集材料，第3或4步运用；家长层说明史书记载需要继续核对。“纪传体通史”、五种体例和篇数供家长阅读，不增加儿童术语考试。需给国博同页的司马迁分节单独登记准确的来源用途，不能仅借用“鉴真”来源名。

### 2.3 徐霞客：补一个有名字的研究问题

**当前缺口：** 现有五步重在看河与桥、画进本子，容易成为适用于任何旅行者的观察练习。研究事实卡已有“实地与旧籍比较”“江河源流”，但儿童主线未展开具体问题。

**核验依据：** 李晓杰的研究介绍明确讨论《江源考》、对“岷山导江”旧说的质疑及金沙江上源问题；也说明徐霞客是在前人相关记载基础上考察、辨析，不能夸写成首次发现金沙江或走到现代认定的长江源头。[全国哲学社会科学工作办公室所载研究](https://www.nopss.gov.cn/n1/2023/0823/c448861-40062310.html)

**儿童短句候选：** “徐霞客不只写山水好看，还想弄清河水从哪里来。他把旧书的说法和沿途见闻放在一起比较，遇到不同的地方，继续查。”

**动作与可观察理解：** 第4步从“离开前记下来”深化为“图上记录与眼前水流不一致，回看哪里”；孩子能指出需要比较、核对。真实金沙江与岷江问题放在开场的一句故事或家长可展开材料中，教学水路图明确标为模型，不伪造徐霞客某天的行程。

**落点：** 优先把底稿已有研究转入儿童讲述，不必先增加大批新事实卡。家长页给《江源考》问题、采用资料和解释边界。

### 2.4 鉴真：把“讲授佛学”说得具体，补到达后的时间线

**当前缺口：** “受邀—带书—传授”已经成立，但还缺少人物独特贡献。“佛学和文化”范围过宽。底稿虽提到戒律、弟子营建，儿童故事和材料讲述仍较笼统。

**核验依据：** 唐招提寺官方介绍将受邀传戒、到日后在东大寺活动、759年开设戒律道场分开，并说明金堂由弟子如宝等人在8世纪后半继续完成。现存金堂不能讲成鉴真到岸时就有的建筑。[唐招提寺官方沿革](https://www.toshodaiji.jp/s/about-j.html)

**儿童短句候选：** “鉴真受邀到日本，向僧人传授佛教戒律，也就是他们修行生活要遵守的规矩。后来，弟子们继续讲学、营建寺院。”

**动作与可观察理解：** 仍可使用带书和学习场景，但让孩子知道“这些人具体来学什么”；材料相册或家长层分开到达、讲授、建寺、后续营建。年份由家长读，不强迫孩子记数，也不把历史上的宗教规矩变成对孩子的要求。

**落点：** 第2、4步及真实寺院说明。保留与玄奘的方向、任务对照。

### 2.5 黄道婆：补“改进哪些环节、在哪里传播”

**当前缺口：** 当前动作主要是棉花—纱—布与经纬交错，能理解织布，却还不容易说清黄道婆的贡献。底稿已有捍、弹、纺、织，但在儿童层被压成“改进方法”。

**核验依据：** 国家级非遗项目条目说明从崖州带回的技艺、乌泥泾的传授以及多个工序的改进；华东师大展览补充海南黎族学习背景，展出三锭纺车等传承工具。现代展品不是黄道婆用过的原件，也不能据照片证明某项工具由她一人从无到有发明。[非遗项目资料](https://www.ihchina.cn/project_details/14281/)、[华东师大博物馆展览](https://digitalmuseum.ecnu.edu.cn/huangdaopo/index.html)

**儿童短句候选：** “黄道婆把在海南学到的手艺带回乌泥泾，也就是今天上海一带。从处理棉花到纺纱、织布，她改进方法，再教给乡里的人。”

**动作与可观察理解：** 让孩子分别指出“纺成线”和“交错成布”，再把学习、改进、教给别人连回人物；不把所有环节都合称织布，也不将平纹交错宣称为她的独创。若扩展去籽、弹松或纺车对比，先补逐工序依据与可辨认材料。

**落点：** 第1、2步补传播地点与技术环节；现有经纬学具保留其有限用途。三锭纺车适合作家长或材料扩展，尚不直接增加新操作。

### 2.6 贞观之治：补“安排怎样影响恢复生产”

**当前缺口：** 目前多数动作是找说话者、记录者和耕作者。“减轻部分负担”“给时间种田”已有一句说明，但孩子还没比较过安排与生产的关系。

**核验依据：** 张国刚的相关书摘引用《贞观政要》卷八《务农》，讨论不误农时、轻徭薄赋与恢复生产。采用这条有限关系，不采用英雄化概括，也不推出所有人负担同时消失。[中国全民阅读网所载书摘](https://www.nationalreading.gov.cn/tshzx/202403/t20240314_837899.html)

**儿童短句候选：** “唐初需要恢复种田。朝廷减轻一些赋役负担，也重视给耕作留出时间。农忙时若总被叫去做别的事，就会耽误田里的活。”

**动作与可观察理解：** 选择题由“谁在听、谁在耕”深化为比较两种安排是否耽误农时；孩子能说明“要留出种田时间”。两种图是教学情境，不能写成魏征某次真实视察或某条未经核实的具体诏令。

**落点：** 第2步解释一种具体负担，第4步比较安排，第5步回到劳动落实。补充分节来源，不只用国博朝代概述支撑每个制度细节。

## 4. 不建议为了“内容更多”而添加的东西

- 秦尺真材料缺口仍存在。现有汉尺、明墙、汉关均有年代说明，不能换一个标题就当秦代原物；后续优先补真材料及其身份。
- 不扩写李白、杜甫、李清照作诗当晚的房间、天气与同行者。诗句、可靠背景和现代意境图各自保留边界。
- 不给四大发明补一个统一“发明日”，不把蔡伦、毕昇或黄道婆写成独自完成整条技术史的人。
- 不为丰富人物故事而添加名言现场、童年轶事、具体对话或成功动机，除非有足够依据并标明材料性质。
- 不把更多事实直接塞进每屏正文。新增关键事实应替换较泛的句子，普通大字块仍不超过90个汉字，第一屏短节点合计不超过120字。
