# 2026-10-10 · 统一页面栅格与左右对齐

## 本轮目标与范围

用户指出主内容左右错位、上方留白零散，整体缺少稳定设计规则。本轮收敛顶栏、封面与游戏的内容外框、分栏、页面起点、跨栏元信息、反馈和操作区，并修复同组选项因标签换行造成的底边不齐。所有改动通过共享组件作用于当前44章；未改史实、题干、图像源文件、声音台词或进度机制。

## 布局规则

- `globals.css`集中维护1220px内容外框、24px侧边距、80px顶栏、7:5分栏、32px栏距、16px组间距与24px卡片内边距。
- 封面和ObjectWorkbench使用同一外框及分栏；年代和情境独立跨栏，两侧主内容从同一顶边开始，取消各自垂直居中。
- 右栏用workbench-footer组织反馈与动作，标准区域在可用高度内采用最高560px的最小高度，主操作位置保持稳定；长内容按实际需要排布，不通过裁切隐藏按钮。
- 真材料在卡片内完整显示，故事图保留原比例、取景与热点关系；学具共享几何不变。
- 所有选项外层与按钮使用等高伸展，单行/双行标签不会造成卡片底边不同。
- `.alignment-copy span`原来把52px箭头字号作用到段落中的span，改为直属图标选择器，文字恢复原19px说明字号。
- 结束页保留明确的居中阅读版式，采用统一上下间距，不强行变成两栏。

源码：`app/globals.css`、`app/workbench.css`、`app/ObjectWorkbench.tsx`、`app/page.tsx`、`app/home-navigation.css`、`app/quest-navigation.css`。规则写入AGENTS、设计方案与实施指南。修改前备份在`work/layout-system-2026-10-10/before/`。
