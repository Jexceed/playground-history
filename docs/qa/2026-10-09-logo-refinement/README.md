# 品牌Logo修订 · 2026-10-09

用户反馈首版的历史意味不明确，且没有呼应主页的历史长河与小小旅行团。此次只修改品牌标识及其网页、Mac派生图，不改主页长河插画、课程、声音、章节范围或学习记录。内容版本保持0.68.0。

## 构图与角色

- 前景为三位小伙伴共同拿着展开的旅行地图；背景的蓝色长河与地图中的河流相呼应。
- 长城城楼和短段城墙提供可辨识的中国历史线索。它们属于品牌意象，不冒充特定地点或朝代的复原图。
- 黄衣男孩保留翘短发与蓝包；女孩保留高马尾、橙色花发夹、红衣与黄包；绿衣男孩保留齐刘海、圆框眼镜和紫包。
- 以主页`history-tour-river-v4.webp`为角色与画风参考，为正方形图标重新组织画面。没有修改原主页插画。

## 原图与生成

采用内置image_gen，无API-key CLI。主提示词见[logo-prompt.txt](logo-prompt.txt)，透明外缘修整提示词见[logo-cleanup-prompt.txt](logo-cleanup-prompt.txt)，实际生成路径、项目内原图、尺寸、alpha和SHA256见[logo-output.json](logo-output.json)。

当前源图：`reference-assets/branding/history-trip-logo-v2.png`，1254×1254 RGBA。旧v1和v2初稿均保留；原图按项目规则不进入普通Git。PNG派生图进入网页品牌入口与页签，ICNS进入App图标。网页资源URL加`?v=2`，避免沿用首版缓存；Mac资源收集器按既有规则去除查询串后打包。

## 已检查的图像

检查最终原图、512像素预览以及32、64、128像素导出。128像素下三个人物、地图、眼镜与城楼可辨；64像素保留三位伙伴、蓝河和城楼的主体；32像素主要依靠三个人物色块、蓝河与金色边框识别，不要求读出砖缝或花发夹细节。原图及PNG保留透明通道，四角透明。只用系统sips缩放、iconutil组装图标，未用代码重画人物。
