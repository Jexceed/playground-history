## 内容、材料与生成

首步用真实材料和可听时代线索；故事图承接三位小伙伴，选项和选中的学习卡保持同款。普通题的短引导自含前提与问题；图中多问和模型操作全部完成后才出现下一步。

桥、水位和孔洞共用几何；水未涨到小拱时不画成已过水。织布相邻排和相邻列的上下交叠均交替。宫灯分开遮光和导烟，说明仅是功能模型，不表示完全无烟或完整文物内部复原。

历史图像来源、摄影者、许可与边界在`content/assets/china-expansion-assets.json`及`reference-assets/china-expansion/ATTRIBUTION.md`。图像来源文件页元数据保留于本QA的material-metadata和qin/han metadata JSON；发现性搜索/OCR缓存已放入忽略的`reference-assets/china-expansion/research/`。原图与PDF不进入普通Git。

生成插画使用内置image_gen工具，参考既有三个儿童的角色约定。实际提示词和结果路径见`art-prompts.json`、`art-prompts-batch2.json`、`art-prompts-batch3.json`；原图保存在项目reference-assets内，运行缩图由既有构建脚本生成。未调用API-key CLI替代。`author-expansion.py`、`register-materials.py`、`fetch-materials.py`只保留最初生产过程，后来校对已直接进入正式源稿，**不可重跑覆盖最终内容**。

书影复核要点：明刊《论语注疏》不是孔子手稿；《史记》卷前为后世《索隐序》，含后人收藏痕迹；《漱玉词》清光绪辛巳1881年刊本扫描第6页有本章词作；MIA郑燮竹石画题款不等于本章《竹石》诗。杜甫当前用真实后世《杜工部集》封面，诗文独立引用教育资料；准确诗页仍是可改进材料，不冒称已经取得。黄道婆当前首步为现代纪念馆照片，织布模型不冒充她使用的原机。

语音沿用`npm run voice:update`增量流程；生产日志见`voice-update-initial.log`、`voice-update-question-cues.log`、`voice-update.log`。初次少数联网合成失败经原脚本重试后完成，最终清单失败数0，原音频不被失败写入损坏。后续纯布局与家长文字改动未重合成。

## 实际页面验收

唯一目标是当时IAB内容区域**1280×720，DPR2**，未追加多端矩阵或视口覆盖。真实URL为`http://127.0.0.1:4173/`，生产服务已用最终构建在原4173端口重启，并实见44章、11站与三个专题。

`browser-checks.json`记录10章加火药共55个不同步骤的全程：普通题先错选再重试；找图多轮均完成且最后只标当前对象；新模型各阶段不能提前前进。每步反馈后、下一次点击前，读取按钮完整边界、祖先裁切、遮挡和scroll位置，失败即抛错停止。所有11章的结束主导航最终均通过；返回时间河与再玩本章实点核对。结束亲子动作展开后回到页面原点复核，两项按钮仍完整可见。

本轮修复了结束图内联height:auto覆盖CSS而挤走导航的问题；初次失败记录保留并标resolved。另一次展开控件自动滚动触发检查失败，未把滚动后结果作为首屏通过；已在原点重新验证。纯桥示意、图外标签和家长页修订后，复走了宫灯、赵州桥并核查家长页，不重复声称所有55步都在最后一份CSS修改之后走过。
