## 发现的问题（按影响排序）

1. **朝代选项卡文字与 🔊 听选项按钮重叠（多章，窄屏）**。`bench-option-sound` 绝对定位在卡片右上角，`era-object` 文本列未让位：6 字名（开元通宝始铸/开元年间开始）字形被压住，5 字（魏晋南北朝）"南"字被压，4 字临界；年份也会断行（"220—589/年"）。证据：`issue-kaiyuan-sound-overlap.png`、`issue-era-longname-0501.png`。建议：卡片文本列给右上角留出按钮位（如 `padding-right`）或声音按钮移出文字区。
2. **"故事插画"身份标签被观察对象遮挡（两处确认）**。
   - 秦章第 2 步（ruler-pairs）：窄屏样式把标签移到左下，被尺子 SVG 叠住，"故事插画"只显示"故事插"（多点探测：标签右侧 30% 被 SVG rect 覆盖）。证据：`issue-badge-ruler-s2.png`。
   - 李白章找图步：标签压在热点虚线框上，虚线穿过文字。证据：`issue-badge-hotspot-libai.png`。
   - 违反"标记与图像身份标签避开观察对象"原则。建议：含底部学习道具叠层或整图热点的步骤，标签改置左上/右上，或整体提高标签层级并避开叠层区。
3. **缺 favicon**：每页控制台报 `/favicon.ico` 404（仅有的两个控制台错误）；浏览器标签无图标。补一个图标即可。
4. **首页"下一站，谁在河边等你？"在 340px 断行为"谁在河边等/你？"**。可在"河边"后换行或调整字号。
5. 站点面板头部"年份 · 儿童线索"连排在窄屏断行零碎（如"前221年—前207/年 · 拿同一把尺…"）。建议年份与线索分两行。

1. **朝代选项卡声音按钮移到卡片外右下角**（`app/workbench.css` 末尾）：`.bench-choice:has(.era-object)` 改 flex 纵列，`.bench-option-sound` 改静态流内。根因：按钮绝对定位在卡片右上角，长名称字形被压——340px 与 1280×720 都存在（Range 测字形边界确认），故不按媒体查询限制。
