## 本轮代码修正

工具题将砝码的objectView从evidence改为weight；尺子与砝码同为学习道具示意，选择后桌面复用同一组件。真实铁权照片仍在首步主图和证据入口。工坊组件不再接收evidence[0]作为选项图片，清理旧照片选项样式。

全库审计新增同组选项技术呈现检查与支持的道具类型检查。实际用两个仅存在于内存中的回归样本验证：旧evidence选项和SVG/位图混搭都会被拒绝；没有修改磁盘运行包或原有审计报告。该检查不能判断两张位图画风是否一致，人工视觉复核仍必需。
