# 原主页恢复与秦朝单章试样

版本：0.64.0。日期：2026-09-13。范围：恢复原时间长河主页、恢复已有历史照片的入口展示；深入修改仅限秦朝“统一度量衡”一章，其他33章逐题稿不变。用户未对本次样章作体验验收，真实儿童测试未进行。

## 这次实际改了什么

- 原来的长河插画、旅行徽章、纸张背景、标题排版和横向站点入口回到首页。仍只开放此前选定的34章。
- 秦铁权实物照回到封面与任务中的观察入口，点开可听照片说明；其他章节的已有照片回到故事卡和封面。
- 秦朝使用一张工坊故事插画作为操作桌面。尺子的格距、长度和位置由界面组件准确绘制，图像模型不负责画刻度。
- 点选可以直接给出反馈，听名字用独立喇叭；第4步真正拖动青尺去对齐黄尺，支持触屏、鼠标、键盘和箭头。错误拖放单独提示“还错开了一点”，不会读成功句。
- 结束页的尺子能反复挪动，孩子可以和家长交换角色，不用勾选“我试过啦”代替动作。
- 仍共用原章节入口、五步状态机、声音队列与进度，只有秦朝数据启用 object-workbench 表现。
