# 2026-11-19 · 62个可玩章节的内容与文字复核 QA

## 1. 背景与发现的系统性问题

根据用户对远古农耕章第1步文物图下方突兀词典胶囊框（`新石器时代`、`彩陶盆`）的反馈，以及“审视一下所有章节的内容展开和文字描述，优化不合理的内容和文字”的指令，本轮逐章逐题审视了当前展示的 **62章310步（15站）** 源稿、专题路线、学习地图、儿童词典及共享渲染组件，归纳并修复以下6类问题：

1. **儿童层底部词典胶囊框（`ConceptChips`）挤占画面且混淆选项（25章34步）**
   - 2026-11-18 引入的 `ConceptChips` 在27章36步显示带边框和喇叭图标的词语按钮。其中25章34步显示较长释义，既压缩文物与插画留白、外观类似答题选项，又违背儿童层“不假设识字、词意进入入场语音、详细词表归入家长层”的原则。
   - **修复**：移除 `ConceptChips` 按钮组件与 `.step-concepts-bar` 胶囊框，恢复秦朝（`度 / 量 / 衡`）与汉五铢钱（`五铢钱 / 五铢`）第1步原有的无框三/五字短拆解标注，并在 `scripts/prepare-focused-quests.mjs` 将 `step.concepts` 限定为 `term <= 6` 字、`meaning <= 10` 字；其余章节所需词意自然融入实际播放的 `story` / `narration`，同时在 `content/child-language-glossary.json` 补齐 `新石器时代`、`粟`、`岁修`、`竹简`、`刊本`、`铁券`、`海塘`、`火药`、`石灰` 9个词条（全库词典升至150词），供家长入口核对。
2. **21个选择题步骤的实际入场语音（`audio.lead`）漏读问题或未问先答（18章21步）**
   - 魏晋、隋、唐、宋、元、明、清共18章21个选择步骤在精简 `narration` 时只留陈述句（如“明朝1368年建立，我们先到明朝。”或“低头思故乡。眼前看过月亮，心里又想起家乡。”），导致不识字的孩子听完入场语音并未听到问题，甚至提前听到答案。
   - **修复**：逐条重写这21步 `narration`，在保持解题前提、时代线索及各章长度上限（秦45字、汉/晋/唐重点章48字、全库≤90汉字）的同时，确保每个选择步骤的实际入场语音以清晰问句收束。
3. **世界章节连读双问句、儿童语音夹带成人编辑免责声明及语病标点**
   - 世界章节4章6步（朵拉维拉第4步、罗马道路第4—5步、欧洲手写书第4—5步、大津巴布韦第5步）在 `story` 末尾已带问句，合成 `narration` 时又直接拼上 `question`，形成生硬的连续两问；现已改为“情境状态陈述 + 单一明确提问”。
   - 清理儿童入场语音中的生硬成人说明腔（如“这是一个虚构的安家故事”“这是一段教学故事”“这是小伙伴另编的会见故事”“这是今天的小伙伴在做练习，不是徐霞客的真实旅程”“图中人不是一份真实合影”“我们的新画卡没有照搬那种布局”“诗中的强烈说法不是请小朋友模仿”“这幅新画不是烧制方法”、丝绸之路第5步突兀的“不是张骞的日记”、王安石第1步成人口吻“政治家和文学家”），改为儿童可听懂的画面与史实引导，详细史料边界统一保留在家长层。
   - 修正多处语病与标点：五代十国第1步“免罪铁牌铁券”重复、青瓷与莫高窟封面语音缺少句读（“青瓷小小旅行团出发！”）、《春晓》第1步漏“的”字、《史记》第1步漏书名号、承德第1步倒装“开始建造在清朝”、远古农耕与甲骨选项中的括号书面语。
4. **收尾总结句（`closingLine`）、结束标题（`finish.title`）与出发按钮（`cta`）模板化或串章错位**
   - 6个世界章节的 `closingLine` 原样粘贴了无标点的章节问题标题（如团聚插画下直接显示“金字塔为什么要建”）；宋代4首新诗的 `closingLine` 原样粘贴了53—62字的整段 `outcome`，与下方 `.final-answer` 完全重复；于谦《石灰吟》误粘了《画鸡》/《芭蕉槛》的“诗里有景物，也有声音和心愿”（《石灰吟》并无声音线索）。
   - 13章共用“把诗里的发现带回家”/“带走自己的发现”泛化结束标题，7章共用“一起去听诗”/“带着问题去看看”泛化CTA，明朝6章第1步共用同一小标题“从真实材料走进明朝”。
   - **修复**：为上述章节逐一补写贴合本章史实或诗意的短句收尾、独立结束标题、具体出发CTA与明朝各章第1步标题。
5. **占位反馈语、`scene-find` 首轮提问不一致、`look-listen` 阅读提示误写“听清问题”与冗余 `displayText`**
   - 唐代5章13步使用“一起接着看。”“继续看线索。”占位反馈（含3个 `scene-find` 互动步），已全部改为对应文物/诗句的具体观察回应。
   - 9个 `scene-find` 步骤的右侧主气泡 `question` 与首轮语音 `rounds[0].question` 同步对齐。
   - 51个纯阅读步骤（`look-listen`）的提示从“听清问题，看看图里的线索。”修正为符合当步内容的“听完故事，点继续……”。
   - 清理长城、五铢钱、江南青瓷4个非阅读步残留的“听问题，找出有用的工具。”遮蔽文本，让家长页准确展示当步故事。
6. **家长层文本整段重复、学习地图孤立主题名与模板关联说明、专题路线年代乱序**
   - 14章在 `finish.parent` 中整段重复粘贴了紧邻显示的 `boundary`（含多余半角空格），已重写为各自具体的亲子提问、可接受回答与易混点提醒。
   - `content/learning-map.json` 中5个孤立主题名归并回家长筛选器使用的6大标准主题，13条模板化 `related[0].relation` 替换为真实历史/方法联系。
   - `content/play-routes.json` 中“先从古诗出发”（清郑板桥混入宋明之前）、“人物与经典”（明→清→明→唐→宋→明跳跃）和“看看世界古代”（与导语顺序不一致）重新排列。古诗与人物路线按朝代分组，世界路线跟随导语介绍各地的顺序，语音与路线一起更新。
