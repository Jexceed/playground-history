# 孝文帝迁都节点核对

洛阳市人民政府公开地方史志《大事记》PDF第103—104页，依据太和十七至十九年的连续条目：

- 493年：到洛阳后宣布迁都，随后安排经营洛阳。
- 494年：记迁都洛阳。
- 495年：朝廷用语等新规定。

URL: https://oss.ly.gov.cn/upload-file/files/20241218/4bf4f3e74241441c9b6f9dc5f46ace8f.pdf#page=103

国博元羽墓志页用493年描述迁都，民委文章有490年的表述。本轮不拼接不同口径；核心儿童页用北魏5世纪，家长层以地方史志拆分过程，保留依据。PDF已实读对应两页文字，不仅引用搜索摘要。
