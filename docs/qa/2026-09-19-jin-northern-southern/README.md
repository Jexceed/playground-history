## 真实材料与事实边界

- 新增北齐陶牛车照片：Gary Todd，CC0，原图位于 `reference-assets/three-kingdoms-jin-northern-southern/northern-qi-ox-cart.jpg`。器物身份由国博条目支持，照片身份/许可另查开放文件页；不冒称博物馆官方摄影。它是墓葬陶车模型，不能编造某家人的迁徙路线或车主。
- 新增国家图书馆《九章算术》1936年印本扫描：原PDF及第3页书影留在同一素材目录。开放扫描的公版标识已登记，按原样渲染，现代条码保留。明确是后世传本，既不是刘徽原稿，也不是祖冲之手稿；数学成果由中科院材料支持。
- 复用三国吴青瓷羊形器、东晋鸡首壶、云冈第20窟、北朝陶俑及第257窟鹿王壁画局部。羊形器用途有不同解释；鸡首壶的墓葬用途不能泛化为每家日用品；服装不能单独识别族群；一件青瓷不能证明全国丰收。
- 孝文帝迁都的不同年份不拼成一条模糊事实。实读洛阳地方史志PDF第103—104页，拆分493年宣布与经营、494年迁都、495年朝廷语言规定，儿童只定位北魏5世纪。详见 [年代核对](date-crosscheck.md)。
- 原鹿王壁画从两端向中间展开，现代学习画从左到右，是教学组织；原图只是局部。它是佛教故事和古代艺术，不能当作北魏人物传记或真实动物新闻。
