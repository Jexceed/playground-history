## 问题与改法

上一版将夯土纹理裁成正矩形，没有墙顶、墙身厚度、落地和沿山势延伸的关系，确实像木板。此前源码/判定通过未发现这个建筑语义问题，旧报告已补记用户反馈并保留原截图。

这次使用内置 **image_gen** 生成完整山地土石城墙场景，再编辑出中央缺口底景。前景有可见墙顶、墙面、石块和墙脚；两侧墙体向山地延伸。教学画不冒称具体秦墙遗址或古代现场，不以明代整齐砖垛、箭楼代替秦墙。

活动墙段从同一幅完整图按墙顶、墙脚的斜轮廓裁取，缺口底景仅在局部显示，周围山地不跳变。原滑动、箭头与判定机制保留；活动件随横向偏移略向前景移出，归零时回到精确位置。拼合成功直接恢复完整场景，去掉绿框、箭头提示与缺口虚线，墙顶和墙面连续。
