# 找图选中前后差异 · 2026-10-20

用户指出四角版仍主要靠蓝色变绿色区分，兵马俑照片里选中前后不明显。本轮在已提交的df1d022之上修改共享找图CSS；此前其他未提交工作保留。

## 本轮变化

- 未选仍为短四角。所选角标改为更长的四角，线宽从2px到3px；框内透明。
- 所选范围保留原图亮度，范围之外加28%半透明深色阴影，让目光能定位当前对象。阴影只在图片内显示，不改变照片文件、取景或点击矩形。
- 答对后收起其他已锁定候选角标；下一轮恢复所有角标和图片原亮度。错选时其他候选仍可点，直接改选后聚焦跟随新对象。
- 正误文字与勾叉仍在右侧，不在人物或器物上叠加标签。240ms角标收拢动画仅为辅助，静态状态仍有差异；全局减少动态效果规则继续适用。

[设计依据](DESIGN.md)。没有改题干、历史解释、答案、声音、完成逻辑、素材或内容版本；也没有批量调整热点。
