# 2026-10-10 · 孔子章内容加深

## 用户反馈与本轮范围

旧孔子章没有在开头充分介绍人物与贡献，也没有孔子像；以拍手示范解释“学而时习之”，缺少值得学习的具体内容。本轮只修改原孔子ID `cn-ancient-03-03-hundred-schools`，不把这一例的修改当作其余43章都已通过内容深化审核。

## 已实现

- 开场说明春秋鲁国、开办私学、不同出身的人学习、创立儒家及后世影响；采用约1770年佚名孔子画像，明确标为后世作品。
- 先教《论语·卫灵公》“己所不欲，勿施于人”的具体含义，再在借画笔、隔一天听同伴讲话、面对暂时拒绝三种情境里运用。
- “学而时习之，不亦说乎”包含温习、实践与快乐；既有“不亦说乎→不亦悦乎”的合成校音继续使用，不把它弱化成答对或机械重复动作。
- 新画面沿用三位固定小伙伴。两幅主场景和六个选择分镜均为现代教学插画；历史人物肖像与明刊《论语注疏》单独标明身份。
- 家长可看原文、现代意译、当前实际台词、八条针对孔子的事实卡、人物贡献、现代应用边界和亲子观察方式。
- 共享封面组件可使用已登记历史材料及其身份标签，不再把本章真实材料显示为“故事插画”；其他章默认表现不变。

史实、材料、动作和理解观察对应见[设计表](DESIGN.md)。原七屏与百家争鸣研究稿存于[旧稿存档](../../design/archive/2026-10-10-hundred-schools-before-depth.md)。源文件、旧孔子音频与原记录备份在`work/confucius-depth-2026-10-10/`。
