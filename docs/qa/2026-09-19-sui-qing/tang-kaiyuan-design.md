# 唐朝第一章 · 开元通宝设计准备

状态：本章已完成本轮实现与本机验证，整体24章目标继续推进；见tang-kaiyuan-qa.md。

核心主旨：钱名也是历史线索，但不能把钱名直接当年号。开元通宝在唐高祖武德四年（621年）开始铸行，早于唐玄宗开元年间；“通宝”等命名代表货币标示的变化，规范钱币与交换相联系，不等于人人富裕。

2026-09-19实读中国国家博物馆[开元通宝条目](https://www.chnmuseum.cn/zp/zpml/201812/t20181218_25620.shtml)：始铸621、圆形方孔、欧阳询钱文记载、钱文读序、命名含义、重量标示转向通宝元宝币制。历史事实用已登记`NMC-KAIYUAN-TONGBAO`；不要误把铜钱上的开元当唐玄宗年号，更不能说照片里这枚一定在621年铸出。
