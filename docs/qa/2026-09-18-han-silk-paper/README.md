# 汉朝其余两章：出使见闻与造纸改进

用户认可五铢钱章后，要求继续优化汉朝其余任务。本轮完成张骞、蔡伦两章；不扩展其他朝代或重新设计主页。仍为本机试玩，未提交、未推送、未部署公网。

## 设计与史料

| 章节 | 主旨 | 孩子的参与 | 主要纠正 |
| --- | --- | --- | --- |
| 张骞出使，带回了什么？ | 出使有结盟使命，未达成联盟却带回西域见闻；后来人员、物品、消息继续往来 | 找年代；选择留下见闻的办法；两轮找备食物/整理文书的人；为回信找帮手 | 不把备粮当出使的全部意义，不让前138年张骞从后来设立的玉门关出发，不把封检当成粮食总账或张骞日记 |
| 蔡伦怎样让纸更好用？ | 西汉已有纸，蔡伦改进原料和办法；书写和携带更方便，技术继续完善 | 看早期纸找年代；两轮找树皮/旧渔网；比较写同样多文字时的携带；听伙伴回看已有与改进 | 不编造蔡伦接过旧纸的生平，不把105年当第一张纸出现，不把后世晾架工序当蔡伦改进 |

两章的“史实—证据—动作—理解”详细对应表分别在[张骞源稿](../../../content/chapters/qin-han-silk-road.md)与[造纸源稿](../../../content/chapters/qin-han-knowledge.md)。互动随内容安排，不强制保留拖动；纸章结尾为有回应的短故事，前面已有原料观察和情境选择，后半章没有连续只点继续。

本轮核对并登记：

- [国博“中华史诗美术大展”张骞说明](https://en.chnmuseum.cn/Portals/0/web/exhibition/exhibitions/161120Chines-Epic/)与[国博丝绸之路展览](https://www.chnmuseum.cn/zl/zlhg/201812/t20181220_32385.shtml)，支持使命、结果及后续联系。美术作品本身不当作汉代现场照片。
- [敦煌研究院樊锦诗文章](https://www.dha.ac.cn/info/1018/5661.htm)区分两次出使与其后列郡设关；[国家民委对考古研究员的悬泉置访谈](https://www.neac.gov.cn/seac/c103391/202302/1161310.shtml)支持驿站接待、文书、人员与补给分工。不指定张骞首次行程住在悬泉置。
- [中国科技馆《古代纸张及造纸工艺》](https://cstm.cdstm.cn/cszl/hxzg/wmjl/art/2020/art_35113f84365e4fc789f95e54f26fe2d0.html)与[国家古籍保护中心《中国什么时候有了纸书？》](https://www.nlc.cn/pcab/zlyj/zlyj_djsh/20190418_177780.shtml)，支持已有纸、原料、改进与长期并用；后者引《后汉书》。模拟古法照片、明代《天工开物》均不当作105年工序证据。
- [香港古物古迹办事处的马王堆帛书展览记录](https://www.amo.gov.hk/tc/visitor-centre/exhibitions/heritage-discovery-centre/han-exhibition/ag23/index.html)补充馆藏身份。真实照片沿用已登记的玉门关、悬泉置封检、西汉纸残片、马王堆帛书四件，无新下载照片。摄影许可与历史解释分别保留出处。

原九三学社纸史链接不再作本章核心史实主证。旧编辑长稿保留并注明与当前儿童五步的区别；纸残片照片不用于猜测具体所写内容。王维唐诗与《纸的发明》课程联系留在家长延伸，不替代历史依据。

## 素材与实现

内置 **image_gen** 生成并保存到项目，未使用CLI/API密钥模式：

- [驿站最终图](../../../reference-assets/qin-han/silk-post-messages-v2.png)，[实际提示词](silk-post-messages-v2-prompt.txt)。沿用黄衣男孩和青衣成年向导，明确备食物、整理文书与后方传递人员；不将他们当作张骞肖像。
- [原料桌最终图](../../../reference-assets/qin-han/han-paper-materials-v3.png)，[初始提示词](han-paper-materials-v2-prompt.txt)与[局部编辑提示词](han-paper-materials-v3-prompt.txt)。v2把简册画成圆棍状物，放大检查后局部修为薄平简片编成的册；v2保留并标editor-only，儿童全部引用v3。其他角色、原料与构图保留。

旧驿站、造纸工坊、相聚图及四张真照片保留。真照片独立组成两套相册，逐张有年代、观察点、短声音和来源；原件不修改，首屏只配置取景。

复用现有五步、找图多问、故事图卡、相册与FinishNavigation。新配置`selectionFraming: detail`让选中的局部和图卡共用SceneCardArt裁取，避免同场景不同选项却看不出变化。`familyMode: actions`显示回看故事图、可选相册和具体亲子动作，不回落到尺子或旧小游戏。

首步`panorama`取景减少空景并给按钮留空间；相册仍显示原图。`thumbnailPosition`让玉门关缩略图包含关口而非只有天空；两张照片不再重复成三张预览。未增加设备断点或多端矩阵。
