## 范围

处理用户截图中的三项问题：出发按钮只进秦朝、任务卡插画雷同、续玩横幅压缩主页。基线为2a2bf754，保留原有13项本机临时指针/缓存。没有提交或推送本轮修改。

本轮开始没有已打开的浏览器标签，复用本机4173服务，新建检查页后实测1280×720、DPR 2；没有设置viewport覆盖，也没有追加其他尺寸。旧服务是本项目的vinext start静态构建，构建后仅重启该项目在4173的服务，实际URL与HTTP响应均已确认。

## 实现

- 主出发按钮打开当前全部10个历史站的地图；选择一站后进入原任务列表，站内可返回所有站。沿用useModal的焦点、Escape与滚动锁；地图和站内说明都有暂停、续播与重听。
- 34个任务卡逐章登记coverAssetId与coverDisplay，采用清权实物、古籍、书画与现状照片。所选材料及取景见cover-selection.json；本轮实际使用34项不同材料。不是要求未来每章必须使用不同原物，也不为凑数量另找弱相关材料。
- selectFocusedCover不再按JPG/PNG或名称猜“真实照片”，拒绝项目生成图、编辑专用图、未清权或缺少来源/许可的图。器物与书页完整显示；屋脊复用已有登记的局部坐标。画作、后世刊本、现代展陈与清代重建形制直接标清身份。
- 卡片保留材料、主题和开始动作；人物线索与完整开场问题继续在原章节中展开。presentation故事场景与选章材料分别配置，三位小伙伴的故事保持。
- 续玩变为页头380×42px按钮，位于60px顶部栏内；原独立740×98px横幅移除。进度机制与内容版本保持。
- 公共出发口令改为自由选站；沿用edge-tts增量更新river-intro这1段，其他3019段复用，声音总数仍为3020。没有更换引擎或生成新插画。
