# 汉朝五铢钱章：主旨、史料与互动

实施日期：2026-09-18。用户认可长城的改进后，明确要求后续章节围绕主旨、历史图片与文献、互动性，让孩子在玩中理解真正的历史。本轮先精修汉朝第一章；张骞与蔡伦两章保留原稿并列入下一步核查。

## 规范与章节设计

根 `AGENTS.md`、`DESIGN-SPEC`、`TASK-IMPLEMENTATION-GUIDE` 和单章模板新增“核心史实—图片/文献依据—孩子动作—可观察理解”的对应要求。主旨贯穿开场、过程与收尾，操作必须帮助理解历史；技术通过、看图好看、小游戏成功均不能代替儿童理解记录。

五铢钱章旧稿重心是串钱与泛化的劳动分工。现在围绕“汉武帝为什么统一铸钱”：真钱找到年代，短故事说明钱币轻重不一与朝廷统一管理，学具对照钱形，两轮找钱范/秤，最后分清称量与串钱的不同作用。完整对应表在[章节源稿](../../../content/chapters/qin-han-han-governance.md)。

- 前202年建立西汉、前118年始铸五铢、前113年铸币权收归中央分别说明；本章时间题使用汉武帝前113年。
- 删除“铸钱人→种粮人→运粮人→集市”的无依据单线路径；不从墓中钱币数量推出普遍财富或市场流通状况。
- 钱形学具只帮助观察圆边和方孔，明确不是真实铸钱流程；称量场景为解释重量规格的教学情境，不声称复原逐枚出厂验收。
- 收尾回到朝廷管理、工匠照规格做钱。家长层补原典、准确年代、财政与中央权力背景、图片边界和具体亲子提问。
