**同日第二轮（用户批评后的内容加深）**：用户指出初版“只有玉门关看不出长城的感觉”，要求说清长城的长、防御目的、起止位置、风化与建造方式。本轮重构五步并补来源；明长城全景与秦长城遗址的真实照片因本机网络无法访问 Wikimedia 而未取得（TLS 在 ClientHello 后被断开，DNS 正常），列为待办下载项，见文末。

**同日第四轮（真实全景照片接入）**：发现本机系统代理（127.0.0.1:7890）可连通 Wikimedia——此前直连 TLS 被断是网络过滤所致。经代理下载并登记金山岭明长城全景照片（Severin.stalder，CC BY-SA 3.0，Commons 文件页核对），首步主图从玉门关切换为全景照片（标题与声音明确标注“明代修建，比秦晚很多”），玉门关专任第四步风化证据；章节卡片封面也改用全景照片。Commons 检索确认没有身份明确的秦长城遗址照片（类别不存在、搜索仅得用户自绘地图），缺口继续如实保留。实测第四轮 25/25。

## 本章内容组织（重构后）

- 核心问题：旧墙段、关口、道路和烽燧怎样被接成一套防御系统？
- 五步（第三轮形态）：
  1. **时间（保留朝代定位题）**：玉门关遗址（汉代，秦之后）定位秦朝；《史记·蒙恬列传》“西起临洮、东到辽东、延袤万余里”进首步故事与概念卡（临洮/万余里/辽东）。
  2. **起点 · 看图听故事（长与起止）**：v2 插画远眺蜿蜒长墙，故事讲“像一条长龙，从临洮走到辽东”，接课本《神州谣》“长城长，珠峰耸”；无题，听完点“我看到啦，继续走”。
  3. **旅程 · 唯一动手环节（防御 + 连接）**：叙事点明北边来犯者、缺口挡不住；孩子拖动墙段接进缺口（slide-fit，可箭头/键盘）。
  4. **变化 · 看照片听故事（建造+风化）**：玉门关真实照片（风化的墙）配夯筑故事：“黄土碎石装进木框一层层夯实；两千多年风雨把墙磨矮”。
  5. **回答 · 相聚听讲述（年代接力）**：伙伴们相聚，听“高砖墙多为后来明代修、长城是一代一代接力筑成的”；无题，点“我们把发现带回家”。
- 结束页动作改为“两手当墙段留空→请家人连起来，再说说墙挡住了谁”；家长接话接受“挡住来抢东西的人、保护家园”，不扮演战争。
- 新来源：SHIJI-MENGTIAN（起止与主持者）、XINHUA-GUYANG-QIN-WALL（固阳片石垒砌与防御体系）、XINHUA-NINGXIA-EARTH-WALL（夯土版筑与风化现状）；沿用 UNESCO-GREAT-WALL、CAS-ANCIENT-INVENTIONS-CHRONOLOGY、NMC-QIN-HAN-OVERVIEW。

## 初版（同日第一轮）内容存档

第一轮五步为：朝代定位 → 认低矮旧墙段 → 接缺口（slide-fit）→ 关口与烽燧分工 → 年代判断。关口/烽燧分工点在重构后并入第三步回应与家长层，用户未反对该知识点；五步装不下时优先用户点名的六项内容。
