## 1. 背景与升级范围

针对生长环境中较少接触中国历史与传统文化的4—6岁儿童，按“1. 整体框架升级 → 2. 内容描述与跨文化脚手架修复 → 3. 图片与学具生成替换”三步完成系统升级：

  1. `cn-ancient-01-02-first-farmers`（远古时期 · 河边的第一批村落：水稻、粟米与两种房子）
  2. `cn-ancient-02-02-oracle-bronze`（夏商西周 · 甲骨文与青铜大鼎会讲什么线索？）
  3. `cn-ancient-03-01-iron-waterworks`（春秋战国 · 铁农具与都江堰：江水怎样听话去浇田？）
- **新增启蒙路线**：`content/play-routes.json` 首项新增 `starter`（“历史启蒙第一站：衣食住行、汉字与巧手发明”），串联8个零基础高共鸣任务，复用原章节ID与完成进度。

## 2. 框架、内容与视觉修改清单

1. **整体框架（`app/` & `scripts/`）**
   - **第1步相对时间河条（`TimeRiverRibbon`）**：中国古代（`远古 → 夏商周 → 春秋战国 → 秦 → 汉 → 魏晋 → 隋 → 唐 → 五代 → 宋 → 元 → 明 → 清 → 今天`）与世界古代（独立相对距离标尺 `四千多年前 → 两千多年前 → 大约九百年前 → 六百多年前 → 今天`）严格分轨，帮助不识数的小孩直观看到“离今天有多远”；针对首轮反馈的“夏商周”与“春秋战国”重叠问题，将 `.time-river-stop` 从均分列宽（`flex: 1 1 0`）改为自然字宽（`flex: 0 0 auto` + `justify-content: space-between`），彻底消除多字站名挤压重叠。
   - **可点听儿童词语卡（`ConceptChips`）**：`focused-gameplay.mjs` 为 `step.concepts` 自动生成独立语音并在桌面包完整收录，孩子点按即可听白话解释，家长页同步展示核对。
   - **可逆阶段回看对比（`HistoryLab` & `CircleStudy`）**：保持首次按序操作完成后过关的门禁不变；完成后开放阶段切换胶囊按钮（如对比低水位/高水位、分水前/排洪/灌田、6/12/24边形）。
   - **学具升级与新增**：新增都江堰 `water-split` 分水学具（`DujiangyanDiagram`），并重绘指南针木船船体、织布机已织布面与梭子、故宫琉璃瓦坡屋面及红墙额枋、蒸汽机锅炉与机座。
2. **内容描述与史料边界修复**
   - **火药章（`cn-ancient-07-08-song-gunpowder-records`）**：第3步由泛化的“图书馆展柜与笔记本找图”升级为博物馆历史用途展板（左看古书与城楼信号火箭、右看夜晚街市远望节庆烟火），安全传达军事信号与节庆烟火用途，不含任何配方或点火操作。

   - **五代十国章（`cn-ancient-06-05-tang-decline`）与诗词及跨文化词汇**：平滑铁券第1步入场语音，为《元日》《芭蕉槛》《石灰吟》及20余个涉及器物/地理概念的章节补充可点听白话词语卡。
