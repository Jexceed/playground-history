## 1. 产品目标与当前范围

面向4—6岁儿童与家长共学。孩子跟着三个现代小伙伴沿时间河进入历史，通过听、看、选择、摆放和指认，理解一件文物、一段诗文或一个历史问题。家长可随时查出处、材料边界与可选加餐。

2026-09-18用户再次明确：重点是“在玩中理解真正的历史”。每章须同时落实主旨、历史图片与文献、互动性。主旨决定材料和操作的取舍；实物图帮助观察，文献支持年代、制度与因果，不能用照片自行推导；互动让孩子运用刚看到或听到的历史关系，不能只增加点击和拖动次数。

- 完整内容库：7个板块、112章、560步；当前HTML展示春秋至明清44章、11站，其他68章保留源稿与兼容完成记录。
- 当前认可的是秦朝样章设计方向；各章的实现、材料审核、人工校听、真实儿童测试和内容冻结分别记录。
- 2026-10-08完成原8个候选与孔子、兵马俑共10章制作（9个新ID、1个旧章升级），并补火药用途；[实施方案](design/CORE-TOPICS-2026-10-08.md)与[QA](qa/2026-10-08-china-expansion/README.md)列明证据、互动及边界。
- 用户明确当前只做中国。人物与经典、四大发明、中国古迹三个专题在既有出发地图内选择，复用已有章节和进度；不将国外遗产列为当前任务，也不把项目选题称作官方“八大奇迹”。
- 中国史依据中国课程标准、统编教材与权威机构材料组织。世界史使用独立时间线，不虚构同期联系。
- 宋站中的辽、西夏、金是与两宋先后并立的不同政权；清朝本轮内容截至近代前夜，不表示清朝在1840年结束。
- 2026-10-10用户明确所有能力只以macOS App交付，采用Tauri封装同一套游戏并随包携带资源；原网页工具链保留作历史开发辅助，未经用户明确要求不启动浏览器诊断。内容冻结前不转换微信、不接登录支付、不部署到公网。
- 当前验收针对已安装Mac App的画面、故事、交互和语音，并以当前指定App窗口尺寸为布局依据。用户给出宽高时按指定值，未给出时记录真实App窗口及内容区域宽高。共享源码、浏览器验证和构建成功均不能代替真实App验收；不做多端适配或断点矩阵。

## 2. 已确定的体验原则

品牌标识延续主页的“拿着地图，沿时间河出发”：三位固定小伙伴、旅行地图和长河形成同一画面，以长城城楼等明确的中国历史线索补足主题。品牌图不能仅用书本、山水、拱桥表达抽象的学习与旅行。App图标需要单独检查缩小后的轮廓与角色区分，不能直接裁切整张首页插画。标识属于品牌插画，不作为历史复原或课程证据。

2026-10-10用户认可新版App图标构图并授权替换：三位伙伴与展开的地图集中为主体，时间河留在地图中，长城为次要历史线索；去掉金色厚边与复杂远景，底板按后续反馈使用白色，四周保留留白和干净透明圆角。原主页旅行插画和角色身份保持，详见[白底Logo记录](qa/2026-10-10-logo-white/README.md)。

1. **保留时间长河入口和旅行故事。** 首页提供出发的画面感，章节由小伙伴发现问题、请求帮助、得到回应、分享发现串联。
2. **每章围绕一个具体问题。** 时间、对象、过程、变化、应用形成连续五步；不能套五个空洞问句。
3. **有真实材料，也有可操作的学习示意。** 真文物证明历史依据，插画承担叙事，学习道具表达需要比较或操作的关系。
4. **同组答案统一呈现。** 两项同为相近画风的插画或同类照片，保持比例、背景、清晰度、裁切和标签结构可比较。
5. **儿童不靠识字完成主线。** 大图、明确动作、大按钮与可暂停重播的本地声音共同提供信息。
6. **家长信息有独立入口。** 长解释、资料引用、许可证、证据局限、扩展线索默认折叠。
7. **主行动清楚。** 直接点选或操作后反馈，再进入下一步；结束页按钮必须与去向一致。
   “回到时间河”固定在顶部导航，在章节封面、游戏、结束和家长层持续可见。五个阶段是可点击入口，可自由前后跳转；当前位置和已完成步骤分别标记，点击跳转不代表完成。跳转同步画面、语音与保存位置；顺序继续仍依赖本步问答/操作或阅读确认，全部五步实际完成才增加整章完成标记。
8. **先做一个完整样章，再按用户指定范围推进。** 后续章节沿用已认可原则，不重复推翻主页或擅自扩大改版范围。

## 3. 页面组织

| 页面 | 首要内容 | 孩子主要动作 | 家长信息 |
| --- | --- | --- | --- |
| 时间河主页 | 三位伙伴、长河插画与具体线索，一屏展示 | 拿地图出发、继续上次任务 | 资料总入口置于底部 |
| 时间地图 | 当前可见的11个历史站或三个专题 | 自由选择一站 | 不扩大到隐藏68章 |
| 历史站 | 朝代与年份、以真实材料作封面的任务卡 | 选择故事，或返回所有历史站 | 简短范围说明 |
| 章节封面 | 时代、核心主题、与任务相关的故事画面、一个小难题 | 点“出发”，自动接上兼容进度 | 目标、事实来源、材料边界折叠 |
| 第一步 | 有历史意义的材料与时间定位 | 结合材料选择朝代或年代位置 | 图片身份、出处和许可可查 |
| 中间三步 | 连续情节、当前问题、同组图形选择或操作 | 一次解决一个观察或关系问题 | 需要时点开证据材料 |
| 第五步 | 把发现用到一个具体情境，伙伴加入或产生回应 | 最后一次选择、摆放或指认 | 不把复述变成识字考核 |
| 结束页 | 一句发现、伙伴相聚、清楚的主按钮 | 返回时间河、再玩本章 | 亲子练习默认折叠 |
| 图片大图层 | 完整图片、短说明、重听与关闭 | 看细节、听说明、返回原步骤 | 来源、许可与证据局限折叠 |

首页插画用于时间河。章节封面需要自己的任务语义；不能把同一张首页封面机械复制到站点、封面和第一步。每张图片是否重复，应由本步用途决定，不为凑图片数量另找弱相关材料。

2026-10-10入口简化：顶部续玩条可用×隐藏，重开仍隐藏，既有记录保留，再次出发后恢复；历史站顶部并排提供“所有历史站/换个主题”与“回到时间河”，取消重复关闭×和底部返回长条；开场只保留“出发”主按钮，重听置于标题旁的故事区域，不再提供“接着玩/从头再试”二选一，也不追加旧的“点继续”语音提示。

同日后续：章节正文中的返回链接移至全局顶部，家长目录和详情也共用此入口。阶段条改成带序号与短名称的五个按钮，完成状态独立保存。直接进入最后一步后，主按钮明确指向尚未完成的步骤；全部完成后才显示结束。复用同一chapterId、五步状态和schemaVersion 2，旧完成标记保持。

2026-10-08：主出发按钮先展开当前11站地图，不自动打开秦朝；继续上次任务的入口收进顶部栏。历史站任务卡用已登记、清权的文物照片、遗址今景、古籍书影与书画材料区分题材，逐章明确coverAssetId与coverDisplay。选章用的真实材料封面与进入章节后的故事场景分别配置；入场故事继续保留三位小伙伴的叙事。后世作品、重建形制和现代展陈直接标在卡片上。

同日情境图卡修订：叙事选择以具体人物、器物和动作构成的画面承担信息，不能将通用符号串放大作主画面。单幅情境复用scene-card，先后关系用同组分镜的scene-strip；精确学具仍由共享几何驱动。选项缩图、选中大图、错误项与身份标签均须在本机实际验看。

同日后续确认：删除主页下方重复的“下一站，谁在河边等你？”站点列表，以及旅行插画旁的小字说明。主页以当前窗口为限分配图文空间，完整保留插画与主要行动，不需滚动；只有出发按钮打开选站。主轴依据与插画身份说明移至家长入口，历史站任务列表仍可在弹层内滚动。

### 页面栅格与间距（2026-10-10统一）

共享尺寸在`app/globals.css`的布局变量维护，封面、任务和顶栏共同引用，避免由各个页面单独决定宽度和垂直位置。

| 层级 | 规则 |
| --- | --- |
| 内容外框 | 最大1220px，最小侧边距24px；顶栏、章节封面和任务共用左右边界 |
| 顶栏 | 高80px，保留品牌、返回、阶段选择和声音控制 |
| 页面起点 | 顶栏后32px；年代与当前情境独立跨两栏，行高24px，之后间隔16px进入主内容 |
| 主体分栏 | 左图右文7:5，栏间距32px；两侧从同一顶边开始，不按各自高度分别居中 |
| 内容组合 | 卡片内边距24px，题目、选项和操作组之间16px；问题区至少144px，阅读、选择与操作共用起点 |
| 操作区 | 在右栏下部预留反馈与前进区域，主按钮不随短反馈在屏幕上游移；空间取当前App高度，标准任务区域最小高度上限560px |
| 图片与学具 | 材料卡在可用高度内完整显示照片；故事图保留原比例与登记裁取，学具与热点按原几何缩放 |
| 结束页 | 960px居中阅读版式，采用同一页面上下间距；这是居中总结用途，保留既有结束主导航 |

本轮实物题在同一1512×871 App窗口量得左右卡片顶边原差20逻辑像素，改后为0；反馈出现后保持。该测量是实际截图边线测量，不替代其它题型或儿童理解验收。见[布局QA](qa/2026-10-10-layout-system/README.md)。

### 全流程视觉层级（2026-10-10整体复核）

在主界面栅格之外，地图、站点、材料弹层和家长页沿用同一套留白与控件层级，避免只把主游戏两栏对齐、周边入口仍各自排布。

| 场景 | 规则 |
| --- | --- |
| 弹层外框 | 地图与普通站点宽1080px，单故事站880px，材料1180px；统一24px内边距、24px圆角、2px浅色边线和柔和投影 |
| 弹层导航 | 标题与返回位于固定顶行，正文内部滚动；历史站返回选站与返回主页相邻，材料关闭只收起大图 |
| 任务密度 | 单故事使用横向图文卡，两故事两列，三个以上三列；材料身份贴近封面，出发状态位于卡片底部 |
| 时间地图 | 当前目标窗口内四列展示11站，统一图标、标题、年代与故事数的排布 |
| 材料查看 | 标题独占顶行；左右图文顶边对齐，说明在图下，重听与暂停在同一组，来源默认折叠 |
| 公共控件 | 声音操作复用线框扬声器；家长入口在儿童页底部居中；首页顶栏延续首页背景 |
| 家长入口 | 章节和学习材料优先；学习记录迁移、制作统计、读音规则及编辑音色小样默认折叠，展开后保留原功能 |
| 家长目录与详情 | 同排卡片的统计和查看按钮靠底对齐；只有一个板块时省去切换卡。详情为成人阅读采用5:7图文分栏，仍用32px栏距、同一顶边、36px标题和完整材料缩图 |

本轮不改五步内容、声音文本、材料身份和学习记录格式；完整流程的实际App截图与验证边界见[整体视觉QA](qa/2026-10-10-visual-review/README.md)。

### 选择状态的辨识（2026-10-19，10-20补强选中状态）

找图区域以深蓝细线四角和窄白衬边提示可点范围，框内不铺底色；不画整圈厚边，也不把“找到了”标签盖在手部或器物上。答对用深绿四角，答错用深红四角，正误勾叉与文字放在右侧题目下方。只标记当前选择，不因完成而把未选对象标绿；完整点击范围与热点几何不变。首版双层厚框被用户指出遮挡后已弃用。

2026-10-20用户指出四角版选中前后仍不明显。选中状态改为更长的四角、3px线条和周围画面的轻度压暗，所选部位保持原亮度和透明覆盖；答对后收起其他已锁定候选的角标，下一轮恢复。错选仍保留其他可选目标。短促收拢动画仅作辅助，静止画面也能区分状态；不新增图中标签、不放大或改动照片。

图卡选中后使用同组深色粗边、较明显的浅底色和白边正误标记，描边通过内阴影增厚，避免选择前后尺寸跳变。当前可见图卡与隐藏旧稿的听选共用状态色；隐藏章只做结构检查，不等于内容或实机验收通过。验收以本机App的原窗口、答题前后截图为准。

## 4. 秦朝样章的最终组织

任务ID：`cn-ancient-04-01-qin-unification`。主题：秦统一度量衡。入口难题：工坊里的两把尺，为什么一把长、一把短？儿童带走的关系：共同标准便于比较，量的时候还要核对起点和每格。

| 步骤 | 内容和画面 | 操作与结果 |
| --- | --- | --- |
| 时间 | 展示真实诏书铁权；用短标签解释度管长短、量管容量、衡管轻重 | 在带年代的秦朝、汉朝选项中定位“统一度量衡”；材料和年代选项的关系清楚 |
| 起点 | 工匠和小伙伴发现同样三格却长短不同的旧尺 | 选择每格一样长的一组；图形改变与回应同步 |
| 旅程 | 给同一块布选择测量工具 | 尺子与砝码两项都用统一的学习道具示意；选中的同款道具出现在桌面，真实铁权另从证据入口查看 |
| 变化 | 工匠固定黄尺，小伙伴请孩子核对青尺 | 拖动青尺；也能用箭头或键盘移动。先对起点，再核对每格；未对齐可继续试 |
| 回答 | 两位伙伴来到工坊，请孩子把办法交给他们 | 选择同标准的一组尺；回应明确指出能一起量一量 |
| 结束 | 三位伙伴相聚，一句总结“起点对齐，每一格也一样长” | “返回时间河”“再玩本章”；展开“和家人再量一量”后，把青尺挪开、请家人对齐并指认每格 |

真实材料为河南博物院所藏秦始皇廿六年诏书权；首步和工具题的证据入口均可查看。秦尺照片尚未找到可靠断代且许可明确的来源。现有汉代铜矩尺只作“秦之后的汉代”对照，不能写成秦尺。

## 5. 每个后续任务的内容组织

2026-10-10孔子章内容加深：人物开场包含春秋鲁国、开办私学、有教无类、创立儒家及后世传承，配约1770年的后世孔子像。以《论语·卫灵公》一条待人原则作为实际学习内容，孩子在借笔、隔天听同伴讲述和面对暂时拒绝中运用，再理解《学而》的温习、实践与快乐。现代情境不冒作孔子生平，答对不等同理解。具体史料、动作与观察对应见[设计表](qa/2026-10-10-confucius-depth/DESIGN.md)。本轮只改原孔子章，其余章节不因这一样章就标作内容深化完成。

先选择一个孩子能看见或想到的入口：器物、人物的具体动作、诗句中的画面、建筑细节、地图路径或工艺问题。再确定一条可以在五步里讲清的关系。

| 内容层 | 必须有的内容 | 使用位置 |
| --- | --- | --- |
| 儿童主线 | 年代位置、具体对象、连续拍点、一个核心问题、可观察的回答 | 封面和五步任务 |
| 亲子加餐 | 两个可执行动作或追问、非语言回答方式、文化延伸 | 结束页与家长入口 |
| 编辑证据 | 原始资料、出处位置、事实与推断的边界、图片许可 | 源稿和材料说明 |

五步使用固定ID `time → beginning → journey → change → takeaway`，但每步内容根据题材编排。诗歌可由“看见什么—做什么—想到什么”推进；技术可由“遇到问题—尝试办法—比较结果”推进。不能给每章复制秦朝工坊，也不能给人物虚构亲历记录。

人物、古诗词和成语应参与情节或操作。例如读《静夜思》时，抬头看月与低头思乡可成为动作线索；后世诗人画像只帮助认识形象，不充当写诗当晚的记录。延伸线索服务核心问题，详细名单交给家长。

### 2026-10-11：阶段条与学习模型的视觉收敛

### 三类图的用途

| 图的类型 | 承担什么 | 必须守住的边界 |
| --- | --- | --- |
| 实物与史料照片 | 观察历史留下的证据 | 不AI重画，不补造文字，不放大低清图要求辨字；身份、年代与许可明确 |
| 故事插画 | 小伙伴、工坊、相聚等叙事场景 | 明确为虚构教学表达，不当历史现场复原 |
| 学习道具与图解 | 尺子刻度、摆放、对照、路线等功能关系 | 标明学习示意，不冒充出土器物；选择前后复用同一对象表现 |

同组选项除表现类型一致外，还要人工看比例、光线、背景、复杂程度、标签和视觉显著性。不能让正确答案因更精美、更大或更像照片而被猜出来。需要比较“照片与插画本身”时，必须另写明学习目的并设计专门组件，不能悄悄混用普通选择题。

找图步骤的“故事插画”“实物照片”身份标签统一放在图片下方，不叠在可点区域里。热点坐标和图片取景仍使用原来的共同坐标，不以提高标签层级来盖住虚线或观察对象。

## 7. 角色与美术延续

三位角色的稳定外形见 [角色识别约定](CHARACTERS.md)：黄衣男孩为翘短发、无眼镜；绿衣男孩为圆框眼镜、齐刘海；红衣女孩为高马尾、花发夹。除了衣服颜色，还要靠轮廓和配饰区分。

当前角色主参考为主页v4、秦朝相聚v3和分享图v4。更新任何一个角色时，检查主页、出现该角色的任务场景、结束页、分享图与元数据，避免不同页面变成不同的人。只出现黄衣男孩的工坊图继续复用。

优先使用已有合适素材。确需改图时，把原图作为编辑目标，写清哪些局部变化、哪些人物/背景/动作必须保持；旧源图保留，运行文件使用新版本路径。故事画面使用图片生成工具，准确刻度和功能图形沿用代码组件，二者不能互相代替。

## 8. 不识字也能完成的交互

- 每步一个主要动作。选项默认两项，每一项都有图形和独立声音；选择后立即反馈。
- 选错显示明确的叉号、“再试试”和具体观察提示，允许重选，不只轻微变色。
- 选对显示勾号、短回应和下一步。回应解释本次发现，不重复整段故事。
- 拖动提供箭头和键盘替代；可操作区域要明显、易于选中，不能靠细刻度线做唯一命中区。
- 暂停、重听、返回可找到；切页或选另一项时取消旧声音，避免声音叠加或与画面错位。
- 在当前目标尺寸下检查人物、动作与操作物清楚可见，标签和说明与画面配合；主按钮不能越界、被裁切或遮挡，页面不意外横向溢出。
- 主步骤按内容自然组织，不强制挤进一屏。结束页主要按钮先出现，亲子练习默认折叠。相邻结束按钮使用统一导航组件，图标和文字排布一致，不能混用不同Emoji或首页按钮的特殊样式。
- 不要求录音、背答案或说完整句。指图、摆放和动作可以表现理解。

儿童可见文字短而清楚。普通大字块不超过90个汉字，第一屏短节点合计不超过120字；这只是上限，不是需要填满的额度。

## 9. 声音方案

当前游戏使用已有edge-tts脚本，合成时联网，生成后从本机MP3播放。固定音色 `zh-CN-XiaoxiaoNeural`，语速 `-12%`，音高 `+2Hz`。本机还装有F5-TTS，但游戏当前没有使用它的声音包。

当前秦朝每步自动引导通常约5—8秒，第一步增加文物解释后可略长；以一句短情节和当前问题为目标，不堆叠标题、角色名、故事和同义反馈。时长不是必须凑齐的指标，实际试听决定是否拆段。

修改台词后运行 `npm run voice:update`，复用原脚本增量生成；仅换图或布局时不重新合成。文字、声音ID、清单和页面触发必须一致。`量一量`按用户指定的 liáng yī liáng 处理，完整短语校音不改变“度量衡”的读法。详情见 [语音流程](VOICE-WORKFLOW.md)。

729篇编辑长稿对应的1154段正式配音仍待文字与音色冻结；本机短声音维护不代表正式长配音完成。
