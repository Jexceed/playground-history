# 小小历史旅行团设计方案

版本3.0｜内容原则复核2026-09-22，找图标签位置修订2026-09-25｜当前认可的设计基线

用户已认可秦朝样章的整体展示与交互方向。本文件把这轮结果整理为后续章节的制作依据；本轮另修正“尺子示意与砝码照片混在同组选项”的问题。这个认可不等于全部103章通过审核、真实儿童测试完成或内容正式冻结。

本文件替代2.0中与当前实现冲突的页面、操作和交付描述。2.0完整方案保存在 [历史存档](design/archive/DESIGN-SPEC-v2-2026-09-12.md)；原 `小小历史旅行团设计方案.docx` 是2.0旧稿，不作为当前制作规范。

## 1. 产品目标与当前范围

面向4—6岁儿童与家长共学。孩子跟着三个现代小伙伴沿时间河进入历史，通过听、看、选择、摆放和指认，理解一件文物、一段诗文或一个历史问题。家长可随时查出处、材料边界与可选加餐。

2026-09-18用户再次明确：重点是“在玩中理解真正的历史”。每章须同时落实主旨、历史图片与文献、互动性。主旨决定材料和操作的取舍；实物图帮助观察，文献支持年代、制度与因果，不能用照片自行推导；互动让孩子运用刚看到或听到的历史关系，不能只增加点击和拖动次数。

- 完整内容库：7个板块、103章、515个五步任务；当前HTML只展示秦至清34章、10站，其他69章保留源稿与完成记录。
- 当前确认的是秦朝样章的设计方向。其余章节需要各自完成内容与体验复核，不能把样章通过自动扩大为全库通过。
- 中国史依据中国课程标准、统编教材与权威机构材料组织。世界史使用独立时间线，不虚构同期联系。
- 宋站中的辽、西夏、金是与两宋先后并立的不同政权；清朝本轮内容截至近代前夜，不表示清朝在1840年结束。
- 本阶段交付本机网页，地址为 `http://127.0.0.1:4173/`。内容冻结前不转换微信、不接登录支付、不部署新版本到公网。
- 当前验收针对本机Web页面的画面、故事、交互和语音，并以当前指定屏幕尺寸为布局依据。用户给出宽高时按指定值，未给出时读取并记录当前浏览器内容区域宽高。按用户2026-09-15澄清，只取消多端适配和断点矩阵，不取消当前目标尺寸的显示与操作检查。

## 2. 已确定的体验原则

1. **保留时间长河入口和旅行故事。** 首页提供出发的画面感，章节由小伙伴发现问题、请求帮助、得到回应、分享发现串联。
2. **每章围绕一个具体问题。** 时间、对象、过程、变化、应用形成连续五步；不能套五个空洞问句。
3. **有真实材料，也有可操作的学习示意。** 真文物证明历史依据，插画承担叙事，学习道具表达需要比较或操作的关系。
4. **同组答案统一呈现。** 两项同为相近画风的插画或同类照片，保持比例、背景、清晰度、裁切和标签结构可比较。
5. **儿童不靠识字完成主线。** 大图、明确动作、大按钮与可暂停重播的本地声音共同提供信息。
6. **家长信息有独立入口。** 长解释、资料引用、许可证、证据局限、扩展线索默认折叠。
7. **主行动清楚。** 直接点选或操作后反馈，再进入下一步；结束页按钮必须与去向一致。
8. **先做一个完整样章，再按用户指定范围推进。** 后续章节沿用已认可原则，不重复推翻主页或擅自扩大改版范围。

## 3. 页面组织

| 页面 | 首要内容 | 孩子主要动作 | 家长信息 |
| --- | --- | --- | --- |
| 时间河主页 | 三位伙伴、长河、历史站与具体线索 | 拿地图出发、选历史站 | 资料总入口置于底部 |
| 历史站 | 朝代与年份、几个具体故事主题 | 选择故事 | 简短范围说明 |
| 章节封面 | 时代、核心主题、与任务相关的故事画面、一个小难题 | 开始或继续本章 | 目标、事实来源、材料边界折叠 |
| 第一步 | 有历史意义的材料与时间定位 | 结合材料选择朝代或年代位置 | 图片身份、出处和许可可查 |
| 中间三步 | 连续情节、当前问题、同组图形选择或操作 | 一次解决一个观察或关系问题 | 需要时点开证据材料 |
| 第五步 | 把发现用到一个具体情境，伙伴加入或产生回应 | 最后一次选择、摆放或指认 | 不把复述变成识字考核 |
| 结束页 | 一句发现、伙伴相聚、清楚的主按钮 | 返回时间河、再玩本章 | 亲子练习默认折叠 |
| 图片大图层 | 完整图片、短说明、重听与关闭 | 看细节、听说明、返回原步骤 | 来源、许可与证据局限折叠 |

首页插画用于时间河。章节封面需要自己的任务语义；不能把同一张首页封面机械复制到站点、封面和第一步。每张图片是否重复，应由本步用途决定，不为凑图片数量另找弱相关材料。

## 4. 秦朝样章的最终组织

任务ID：`cn-ancient-04-01-qin-unification`。主题：秦统一度量衡。入口难题：工坊里的两把尺，为什么一把长、一把短？儿童带走的关系：共同标准便于比较，量的时候还要核对起点和每格。

| 步骤 | 内容和画面 | 操作与结果 |
| --- | --- | --- |
| 时间 | 展示真实诏书铁权；用短标签解释度管长短、量管容量、衡管轻重 | 在带年代的秦朝、汉朝选项中定位“统一度量衡”；材料和年代选项的关系清楚 |
| 起点 | 工匠和小伙伴发现同样三格却长短不同的旧尺 | 选择每格一样长的一组；图形改变与回应同步 |
| 旅程 | 给同一块布选择测量工具 | 尺子与砝码两项都用统一的学习道具示意；选中的同款道具出现在桌面，真实铁权另从证据入口查看 |
| 变化 | 工匠固定黄尺，小伙伴请孩子核对青尺 | 拖动青尺；也能用箭头或键盘移动。先对起点，再核对每格；未对齐可继续试 |
| 回答 | 两位伙伴来到工坊，请孩子把办法交给他们 | 选择同标准的一组尺；回应明确指出能一起量一量 |
| 结束 | 三位伙伴相聚，一句总结“起点对齐，每一格也一样长” | “返回时间河”“再玩本章”；展开“和家人再量一量”后，把青尺挪开、请家人对齐并指认每格 |

真实材料为河南博物院所藏秦始皇廿六年诏书权；首步和工具题的证据入口均可查看。秦尺照片尚未找到可靠断代且许可明确的来源。现有汉代铜矩尺只作“秦之后的汉代”对照，不能写成秦尺。

## 5. 每个后续任务的内容组织

先选择一个孩子能看见或想到的入口：器物、人物的具体动作、诗句中的画面、建筑细节、地图路径或工艺问题。再确定一条可以在五步里讲清的关系。

| 内容层 | 必须有的内容 | 使用位置 |
| --- | --- | --- |
| 儿童主线 | 年代位置、具体对象、连续拍点、一个核心问题、可观察的回答 | 封面和五步任务 |
| 亲子加餐 | 两个可执行动作或追问、非语言回答方式、文化延伸 | 结束页与家长入口 |
| 编辑证据 | 原始资料、出处位置、事实与推断的边界、图片许可 | 源稿和材料说明 |

五步使用固定ID `time → beginning → journey → change → takeaway`，但每步内容根据题材编排。诗歌可由“看见什么—做什么—想到什么”推进；技术可由“遇到问题—尝试办法—比较结果”推进。不能给每章复制秦朝工坊，也不能给人物虚构亲历记录。

人物、古诗词和成语应参与情节或操作。例如读《静夜思》时，抬头看月与低头思乡可成为动作线索；后世诗人画像只帮助认识形象，不充当写诗当晚的记录。延伸线索服务核心问题，详细名单交给家长。

## 6. 内容来源与图片规则

### 来源分工

| 要确认什么 | 优先依据 |
| --- | --- |
| 中国史范围与脉络 | 教育部课程标准、统编教材及官方教学说明 |
| 文物、遗址、年代、馆藏与学术解释 | 国家级和省级博物馆、考古研究机构、档案馆 |
| 世界史材料 | 相应地区博物馆、国家图书馆、档案馆、大学馆藏、UNESCO |
| 文学与书画 | 权威版本、教材机构和收藏机构的作品记录 |
| 照片的作者与使用权 | 原始文件页、开放政策、作者授权与许可证 |

事实来源与照片来源要分别登记。同一件文物的开放授权参观照片可以使用，但不能因此标作博物馆官方摄影。商业媒体和百科整理只能帮助发现线索，不能直接支撑儿童正文。

秦朝样章的出处入口：

- [河南博物院：秦始皇廿六年诏书权](https://www.chnmus.net/ch/collection/appraise/details.html?id=512159158709033041)，对应来源ID `HENAN-QIN-26-EDICT-WEIGHT`。
- [中国国家博物馆：秦始皇、秦二世双诏版](https://www.chnmuseum.cn/zp/zpml/csp/202008/t20200826_247416.shtml)，对应来源ID `NMC-QIN-DOUBLE-EDICT-PLATE`。
- [铁权照片原始文件与作者](https://commons.wikimedia.org/wiki/File:Qin_Weight_Iron.JPG)，摄影Zcm11，[CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/)。实际页面使用的缩图与署名在素材登记中对应。

### 三类图的用途

| 图的类型 | 承担什么 | 必须守住的边界 |
| --- | --- | --- |
| 实物与史料照片 | 观察历史留下的证据 | 不AI重画，不补造文字，不放大低清图要求辨字；身份、年代与许可明确 |
| 故事插画 | 小伙伴、工坊、相聚等叙事场景 | 明确为虚构教学表达，不当历史现场复原 |
| 学习道具与图解 | 尺子刻度、摆放、对照、路线等功能关系 | 标明学习示意，不冒充出土器物；选择前后复用同一对象表现 |

同组选项除表现类型一致外，还要人工看比例、光线、背景、复杂程度、标签和视觉显著性。不能让正确答案因更精美、更大或更像照片而被猜出来。需要比较“照片与插画本身”时，必须另写明学习目的并设计专门组件，不能悄悄混用普通选择题。

找图步骤的“故事插画”“实物照片”身份标签统一放在图片下方，不叠在可点区域里。热点坐标和图片取景仍使用原来的共同坐标，不以提高标签层级来盖住虚线或观察对象。

## 7. 角色与美术延续

三位角色的稳定外形见 [角色识别约定](CHARACTERS.md)：黄衣男孩为翘短发、无眼镜；绿衣男孩为圆框眼镜、齐刘海；红衣女孩为高马尾、花发夹。除了衣服颜色，还要靠轮廓和配饰区分。

当前角色主参考为主页v4、秦朝相聚v3和分享图v4。更新任何一个角色时，检查主页、出现该角色的任务场景、结束页、分享图与元数据，避免不同页面变成不同的人。只出现黄衣男孩的工坊图继续复用。

优先使用已有合适素材。确需改图时，把原图作为编辑目标，写清哪些局部变化、哪些人物/背景/动作必须保持；旧源图保留，运行文件使用新版本路径。故事画面使用图片生成工具，准确刻度和功能图形沿用代码组件，二者不能互相代替。

## 8. 不识字也能完成的交互

- 每步一个主要动作。选项默认两项，每一项都有图形和独立声音；选择后立即反馈。
- 选错显示明确的叉号、“再试试”和具体观察提示，允许重选，不只轻微变色。
- 选对显示勾号、短回应和下一步。回应解释本次发现，不重复整段故事。
- 拖动提供箭头和键盘替代；可操作区域要明显、易于选中，不能靠细刻度线做唯一命中区。
- 暂停、重听、返回可找到；切页或选另一项时取消旧声音，避免声音叠加或与画面错位。
- 在当前目标尺寸下检查人物、动作与操作物清楚可见，标签和说明与画面配合；主按钮不能越界、被裁切或遮挡，页面不意外横向溢出。
- 主步骤按内容自然组织，不强制挤进一屏。结束页主要按钮先出现，亲子练习默认折叠。相邻结束按钮使用统一导航组件，图标和文字排布一致，不能混用不同Emoji或首页按钮的特殊样式。
- 不要求录音、背答案或说完整句。指图、摆放和动作可以表现理解。

儿童可见文字短而清楚。普通大字块不超过90个汉字，第一屏短节点合计不超过120字；这只是上限，不是需要填满的额度。

## 9. 声音方案

当前游戏使用已有edge-tts脚本，合成时联网，生成后从本机MP3播放。固定音色 `zh-CN-XiaoxiaoNeural`，语速 `-12%`，音高 `+2Hz`。本机还装有F5-TTS，但游戏当前没有使用它的声音包。

当前秦朝每步自动引导通常约5—8秒，第一步增加文物解释后可略长；以一句短情节和当前问题为目标，不堆叠标题、角色名、故事和同义反馈。时长不是必须凑齐的指标，实际试听决定是否拆段。

修改台词后运行 `npm run voice:update`，复用原脚本增量生成；仅换图或布局时不重新合成。文字、声音ID、清单和页面触发必须一致。`量一量`按用户指定的 liáng yī liáng 处理，完整短语校音不改变“度量衡”的读法。详情见 [语音流程](VOICE-WORKFLOW.md)。

729篇编辑长稿对应的1154段正式配音仍待文字与音色冻结；本机短声音维护不代表正式长配音完成。

现有工坊组件支持时间选站、两组尺对比、工具选择、尺子对齐，以及通用学习道具 `prop`、点选 `pick`、滑动对位 `slide-fit`、阅读 `look-listen`、多问看图找人 `scene-find` 和故事图卡 `scene-card`。秦长城现为时间定位、阅读、接墙、两轮找人、情境选择；汉三章已按各章主旨重做，具体见下文，秦度量衡保持已认可的操作密度。互动数量由内容需要决定，不把“一个拖动环节”当作必要问答的上限。

长城章以“长城为什么要修”为核心问题，开场明确抵御外来进攻、守卫边地。明代金山岭照片用于时间对照，第二幕把秦连接旧墙与防御目的连起来；保留一次接墙模型，第四步让孩子在图中分别找到观察远方和看守关口的人。第五步提出“要早点发现远处动静，先怎么办”，在“请守卫望远”和“请工匠继续修墙”之间选择；主画面同步显示所选场景，反馈说明观察和传信的作用。修筑接力仍是背景，原运料插画复用于同画风选项。临洮、辽东等文献线索放在家长延伸，保留《神州谣》的短句引入，不用汉代玉门关证明秦墙变老。

可选“长城相册”补充六张真实照片：山脊全景、墙顶通道、城楼内部、汉代土墙、玉门关远景与近景。相册在章节封面和材料入口直接可见，每张给一个观察提示，翻图同时更换年代、声音和出处。明代砖墙与汉代土墙、关城用于跨时期观察，不冒充秦代样貌；相册不计答题、不改变五步进度。

阅读步骤自动播放完整故事 `audio.intro`，一次继续直接进入下一幕，不把“听过”伪装成答对。`step-flow.ts`统一声音选择和前进条件，未完成的时间题与操作仍不能跳过。故事短句可通过 `displayText` 与完整旁白分别维护；`visualAssetId`指定本步对应画面，`inspection.placement`区分主证据与补充查看，景物照片的 `framing: landscape`只控制主图构图，大图保留全幅。接墙模型使用统一坐标比例，反馈不移动操作区域。新增表现仍扩展共享组件，不另建章节状态机。

## 11. 制作和验收
