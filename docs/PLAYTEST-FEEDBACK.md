## 2026年9月12日 展示与题目设计需要重做

关联版本：0.62.0（原始反馈）。后续0.63.0已进行34章改动，仍未通过真实儿童体验验收。

记录来源为用户试玩后的反馈，具体以秦朝任务举例，同时指出其他题目可能有同类问题。本记录不作为真实低龄儿童复述测试通过的证据。本次按用户要求登记后续待办，不直接修改游戏。

### 反馈要点

1. 整体展示有问题，需要列为后续待处理项。
2. 每个入口都写“打开5步故事”，没有向孩子说明这一章有什么值得做的事。
3. 秦朝页面下方小字过多，许多信息更适合折叠到家长关心的内容中。
4. “从一件东西出发，先找哪个年代？”的两个选项过于显然，希望体现年代信息，形成有意义的判断。
5. “哪一件证物能先打开这个故事？”中的图片、题干和选项没有对应推进，不容易理解，后面几个问题也有类似情况。
6. “把故事讲给家人听”没有说明具体要做什么，用户和家人看不懂任务要求。
7. 之前提出的古诗词、人物连接仍需落实到体验中；每道题过于干瘪，缺少生动的故事。

这些反馈涉及内容组织、提问方式和学习任务本身。后续不能只调整字号、按钮数量或颜色，也不能用已通过的自动测试和全库操作检查关闭这些问题。

### 待处理清单

#### UX01 整体展示与注意力层次

- [ ] 重审首页、故事选择、封面、题目与结束页，让每屏都有清楚的观察对象、具体问题和下一步动作。
- [ ] 将说明性、审核性和扩展性内容与儿童主线分层，检查视觉上真正突出的是否是孩子要看、要听、要做的事。
- [ ] 秦朝先完成连续原型供用户审阅，再回查全库103章，不能只修一个示例。

验收：未经额外解释，用户能指出每屏要看什么、做什么，以及做完得到什么；后续再用真实儿童操作检验。

#### UX02 入口文案不再反复介绍内部五步结构

- [ ] 检查“打开五步故事”“开始五步故事”等重复文案，改为适合入口位置的简短行动提示；故事卡本身交代具体人物、物件或悬念。
- [ ] 五步结构继续用于统一内容与实现，不要求所有儿童入口反复强调“5步”。

验收：孩子能从图、声音和任务主题知道为什么进入；按钮文案服务操作，不把内部流程名当作故事吸引点。具体文案待设计，不机械给每章套另一句模板。

#### UX03 秦朝封面的小字与家长内容分层

- [ ] 逐项检查人物长名单、制度术语、详细解释、扩展线索和资料说明，默认折叠至家长可展开的区域。
- [ ] 儿童首屏突出具体对象、必要时间位置、一句可听的问题与主要动作。
- [ ] 对故事有作用的人物行动、诗文入口仍可留在儿童主线；不要把人物和诗词全部藏到家长区。
- [ ] 文物、后世作品、学习示意等影响理解的身份边界，保留简短可听说明；完整出处与许可交给家长查看。

验收：不识字儿童无需依靠密集小字完成进入；家长需要的解释仍容易找到，折叠不是删除必要史实或语境。

#### UX04 年代题保留时间信息与辨析价值

- [ ] 重做“从一件东西出发，先找哪个年代？”这类通用题干，说明正在定位哪件事、依据什么线索判断。
- [ ] 年代、时代位置或前后关系按任务需要呈现，并用语音读清，不因儿童不识字就省略有意义的时间信息。
- [ ] 干扰项围绕同一判断维度设计，避免用与秦朝相隔极远且一眼就能排除的选项充数。
- [ ] 检查两选项与三选项是否适合具体问题；数量不作为题目质量的指标，也不简单把题目改成背年份。

验收：用户能说明孩子需要观察或听取哪条年代线索；答对体现了时间理解，而非识别一个显然不相干的选项。

#### UX05 图片 题干 选项与故事同步设计

- [ ] 以秦朝“哪一件证物能先打开这个故事？”为起点，逐步核对当前画面、旁白、题干、所有选项和反馈是否回答同一问题。
- [ ] 将“只是人物”“只是地点”“是能核对的证物”等元分类式模板，改为本任务中有意义、能通过图和声音理解的观察或行动判断。
- [ ] 后续每一步都明确本次观察什么、为什么出现这张图、两个选项分别表达什么；故事推进时相应更新画面组织和候选含义。
- [ ] 同一件证据确实需要重复时，改变清楚的观察重点；不靠机械换图或复用通用形状就认定图文已对齐。
- [ ] 回查全部515步；题干或答案变化时同步处理声音、图片说明和校验规则。

验收：看当前图片并听当前讲述，就有依据区分选项；不能靠阅读抽象分类措辞猜答案。允许保留问号和证据边界，不为配图编造细节。

#### UX06 结束任务必须说明具体做法

- [ ] 重新设计“把故事讲给家人听”，明确孩子先指什么、接着说或做什么，家长怎样回应。
- [ ] 提供与本章有关的简短提问或动作示范，并说明允许指图、动作、补词等表达方式；不只放三张图和一句笼统指令。
- [ ] 示例先教表达方式，不提前自动播放完整结论；需要提示与独立表达分别记录。

验收：家长和孩子都知道要完成哪个小动作、怎样回应、什么时候算完成；不能把“显示了复述页”当作“复述玩法已经清楚”。

#### UX07 用人物 古诗词和具体事件推动故事

- [ ] 将有真实关联的人物、诗词、文学作品、物件与事件融入逐步讲述和提问，形成具体的行动、问题与变化。
- [ ] 检查“课本里的老朋友”是否真正参与主线，而非只在封面增加标签、名字和长说明。
- [ ] 根据题材选择入口；没有合适诗词时不强贴，有文学连接时区分作品表达与历史证据。
- [ ] 逐题审视趣味性：孩子为什么愿意看、听、做下一步，本题是否产生一个新的发现。

验收：用户能感受到人物或作品与本题的关系，题目能接回具体故事；不靠添加旁白长度、名人名单或装饰性插图代替生动表达。

### 后续处理顺序

1. 先针对秦朝画出从故事入口到结束任务的完整连续原型，集中解决上述问题；暂不批量制作新图与新声音。
2. 让用户审阅页面和任务意图，再选人物、诗文、技术、近现代和世界史材料检查同一设计是否适用。
3. 按同一清单回查103章、515步，逐项记录差异与需重做内容，保留全库统一入口与核心结构。
4. 题目、画面、声音按逐任务工单同步制作，再做技术检查、人工图文核对与真实儿童试玩。

以上顺序是后续处理建议。本次仅完成反馈登记，UX01—UX07均保持待处理；不将用户的反馈登记改写为体验已通过。
