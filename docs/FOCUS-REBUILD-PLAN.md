## 完成条件

- [x] 范围：儿童与家长试玩入口仅展示34章；隐藏章节的内容和原有完成记录不被删除。
- [x] 内容：34章各有一个具体任务，170步题干、讲述、两项有意义的候选和反馈逐步撰写，删除元分类模板题。
- [x] 年代：时间位置、具体年代及相邻时代或先后关系可见可听，干扰项不靠跨越极远时代充数。
- [x] 图文：每步主图或学习示意、选项图形、图片说明与问题对应；真实材料与学习示意身份清楚。
- [x] 叙事：人物、经典或具体事件在主线中产生作用，文化连接不只停留在封面标签；没有关联时不强贴诗文。
- [x] 页面：清理“打开5步故事”等儿童入口文案；家长长说明默认收起，儿童屏一屏一问。
- [x] 结束：34章都有可理解的具体动作、提问与家长回应办法，不再仅要求泛泛讲故事。
- [x] 声音：本轮试玩新短稿生成本地声音并逐页绑定，旧音频在生成失败时保留；不提前制作编辑长讲稿的全部正式配音。
- [x] 自检：逐章检查因果、图片、题意、选项及结束动作，保留每章的判断依据和修订记录。
- [x] 验证：全库结构与素材门禁、170步界面操作、移动与桌面目检、隐藏范围、进度恢复、声音队列及测试均通过。
- [x] 交付：更新阶段与进度说明，提供本机试玩和检查记录；不部署公网、不开始微信转换、不标记真实儿童审核通过。
