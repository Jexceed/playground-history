# 设计改进与回归记录

记录日期：2026-09-14。用户已认可秦朝样章的整体方向。以下记录保留实际问题及可执行的防回归检查，帮助其他模型继续制作，而不是把所有历史尝试重新当候选方案。

当前方案以 [DESIGN-SPEC 3.0](DESIGN-SPEC.md) 为准，实施入口见 [任务实施指南](TASK-IMPLEMENTATION-GUIDE.md)。

## 用户反馈与已落地的处理

| 编号 | 碰到的问题 | 当前处理 | 后续修改时检查 |
| --- | --- | --- | --- |
| UX01 | 优化题目时重做了整个首页，丢失原来好看的时间长河和出发感 | 恢复长河、旅行插画和站点入口，作为认可基线 | 先看当前页面；普通章节任务不重画主页；用前后截图确认保留的部分 |
| UX02 | 每个入口都写“打开5步故事”，没有任务含义 | 用具体主题和动作，例如去量布、去排字、去看月亮 | CTA能否解释点下去要干什么，是否与目标页一致 |
| UX03 | 儿童页堆满家长和编辑关心的小字 | 主线保留图片、短句与操作；来源、边界和扩展折叠 | 不读小字能否听懂和完成；家长仍能找到资料 |
| UX04 | 年代题选项过于空泛，没有年代信息 | 使用实际朝代、年代与先后关系，第一步结合主题材料定位时间 | 选项有真实时间依据，不能用完全无关或显然荒诞项充数 |
| UX05 | 题目、选项和主图没有同步，选了一个对象画面仍显示另一个 | 由逐题配置与共享组件驱动画面；同款道具复用于选项和桌面 | 故意选错再选对，逐次核对对象、文字、声音与反馈 |
| UX06 | “把故事讲给家人听”不知道具体做什么 | 结束给具体动作；秦朝可把尺挪开，请家人对齐并指出每格 | 能否用指图/动作表达；不要求背完整答案或录音 |
| UX07 | 每道题很干，人物和诗词只是附加标签 | 核心问题由具体情节和逐步观察推进；文化线索参与主线 | 本步是否接住上一幕，人物/诗句是否改变孩子要观察或操作的内容 |
| UX08 | 章节前两页反复用主页封面，没有语义 | 主页负责出发；封面用工坊；首步用真实铁权；最后伙伴相聚 | 每张图说得清本步用途；重复有理由，不为数量硬换弱材料 |
| UX09 | 真实历史照片被粗糙示意替代；度量衡缺少有意义的实物 | 首步显示真实诏书铁权，馆藏依据和照片许可分别可查 | 主线是否有真实依据；图是否对应这件材料；不能把插画当证据 |
| UX10 | 想讲尺子，却拿不到可靠的秦尺实物照片 | 保留秦尺缺口；汉代铜尺明确标“汉代，秦之后”，只作对照 | 不把相关年代改成秦代，不生成假的文物照片，不误标官方摄影 |
| UX11 | 小伙伴带路的故事感被删；“小旅伴”称呼别扭 | 统一“小伙伴”，恢复工坊发现、求助、回应、相聚 | 不把五步简化成五张孤立问卷；动作与下一幕按钮接得上 |
| UX12 | 原角色与中国主题的设定不一致，替换后两个男孩又过于相似 | 三位现代中国儿童形象统一；黄衣翘发，绿衣圆眼镜/齐刘海，女孩马尾 | 主页、相聚、结束、分享同步；手机小图靠发型和配饰也能区分 |
| UX13 | 语音啰嗦、反复读标题和角色名；“量一量”读音不对 | 短引导与一句回应；完整短语校音；复用已有edge-tts增量脚本 | 自动播放和重听是否同一内容；校音是否误伤其他词；需要人耳试听 |
| UX14 | 选错不明显；结束页选项落到屏幕外；“下一个挑战”实际回首页 | 明确叉号/重试标签/边框；主按钮提前；名称改为真实去向 | 390×600下检查答错、答对、结束、展开总结；实点返回与重玩 |
| UX15 | 图上说明、文物小卡和道具遮住人物或被裁掉 | 证据入口移出画面，控制道具尺寸，保留可见面部和动作 | 在实际窗口看人脸、手部、尺子起点与刻度，不能只看大原图 |
| UX16 | 返回了旧ChatGPT Site卡片，用户看到的不是本机当前版 | 仅交付127.0.0.1:4173，停用会展示旧Site的工具流程 | 实查服务、URL与本轮变化；区分工具排队和页面实际可见；不混用内部标签句柄 |
| UX17 | 工具题一项为画出的尺子，另一项为砝码实物照片 | 本轮改为同组学习道具示意，桌面同步；真照片保留在证据区 | 同组风格、比例、背景、标签一致；全库自动检测技术呈现混搭，再人工看画风 |
| UX18 | 结束页左按钮靠左、右按钮居中，Emoji图标和阴影深度也不一致 | 使用共享FinishNavigation，固定图标尺寸与内容排布，两项统一外框高度和4px投影；图标改为同套线条SVG | 桌面/手机测量两个按钮、图标和文字的基线，检查展开总结后是否越界；不复用首页CTA的特殊span样式 |

## 本轮对UX17的具体修正

`content/focused-quests.json` 的秦朝 `journey` 步，将砝码的 `objectView.kind` 从 `evidence` 改为 `weight`。`ObjectWorkbench` 用与尺子相同的SVG学习道具方式显示砝码，选中后仍使用同一组件。真实铁权的首步主图和 `inspection` 图片入口保留。

删除工坊选择器对 `evidence[0]` 的依赖，避免将第一件实物照片自动塞进某个选项。扩展 `content:audit`：所有515步检查同组选项呈现方式，工坊道具类型必须是组件实际支持的类型。当前69章旧玩法的345步仍是符号/文字选项，165步为双SVG图卡，秦朝5步为统一工坊对象；这里的结构一致不代表所有题目已经适合低龄儿童。

本轮修正的浏览器结果、日志和声音未变核对见 [QA记录](qa/2026-09-14-design-baseline/README.md)。

## 仍需继续处理

- 可靠断代且许可明确的秦尺实物照片。
- 按用户指定范围，用当前基线逐章制作与复核，而不是直接给其余33章贴同一个工坊。
- 在真实手机/平板和4—6岁儿童中记录：是否找到开始、哪里跳过、需要何种提示、能否用动作或短句表达关系、是否把插画当实物。
- 最终音色、重点读音与儿童试听；729篇长稿的1154段正式配音等待冻结。
- 历史2.0设计卡和Word文档与当前基线的差异；使用时按3.0模板逐章升级，不能回退旧交互。

历史记录继续保留在 `docs/qa/`；旧记录中的未完成状态不覆盖新的已完成条目，新条目也不能把未验收工作抹掉。

## UX18结束导航复核

根因是结束页直接复用两套通用按钮类：primary-action是内容靠左的flex且有9px阴影，secondary-action为居中文字、无阴影；两者还嵌入不同系统Emoji。现改为无独立状态的共享FinishNavigation，只转发既有返回与重玩动作。结束相聚插画未修改。记录见[复核结果](qa/2026-09-14-finish-controls/README.md)。
