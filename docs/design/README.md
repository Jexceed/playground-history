# 设计制作资料导航

先阅读 [整体设计方案](../DESIGN-SPEC.md)，再从 [103个任务设计索引](../TASK-DESIGN-INDEX.md) 选择要制作的任务。

- `tasks/`：103份逐任务制作草案，包含515步的内容和页面组织，以及事实、来源、素材候选、工单与家长提示。
- [任务模板](TASK-TEMPLATE.md)：填写逐句出处、选项图形、反馈、声音与验收。
- [素材与工具工作单](PRODUCTION-WORKBOOK.md)：分配全局组件、主图、选项图和配音等产物。
- `task-specs.json`：便于检索和后续工具处理的设计数据，不是儿童运行包。
- `task-page-wireframe.svg`与PNG：手机任务页分区示意，可继续编辑。

任务卡中的来源是查阅入口，素材是候选。具体原文位置、图形选项、许可使用条件、声音与儿童理解仍需制作和审核后确认。20个任务在设计层调整了叙事范围或表达，但正式章节、图片、音频和运行包没有因此被改写。

`baseline-2026-09-12.json`保留此前实现核对的快照，仅供追溯，不作为产品设计或完成状态的依据。
