# 单章制作与复核模板

适用基线：[设计方案3.0](../DESIGN-SPEC.md)。填写后写回正式源稿，不手工改运行包。当前模板默认两项选择或一个明确操作，不复制固定五个问句。

## 任务定位

- 任务ID、当前是否在34章展示范围：

- 儿童标题、主题、时间与地点：
- 一个核心问题，一句带走的话：
- 一个可见对象和一个可观察的理解结果：

## 五步分镜

每步填写一次：`time / beginning / journey / change / takeaway`。

- 本步学习目的、与上一幕的关系：
- 首先看见的画面、人物、对象和观察点：
- 儿童可见短句：
- 自动短引导及问题，预计播放长度：
- 两项选项/一个操作及其可听含义：
- 两项表现方式、画风、尺度、背景、视角与标签是否一致：
- 选择后主画面如何变化，是否复用同一对象表现：
- 为什么能判断，直接来源是什么：
- 正确回应、错误回应与下一步实际去向：
- 图片查看入口、说明音频、家长来源链接：
- 暂停、重听、退出、继续、资源失败的处理：
- 使用哪些既有组件；若要扩展，如何保持全库共用：
