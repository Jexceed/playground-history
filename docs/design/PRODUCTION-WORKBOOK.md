# 素材与工具工作单

本文件把整体方案拆成可分配的制作工作。它描述应交付的产物，不表示素材已经制作、许可已经确认或正式语音已经生成。

## 首先建立的共用产物

| 工单 | 产物 | 主要工具 | 验收重点 |
| --- | --- | --- | --- |
| GLOBAL-01 | 页面关系与组件状态图 | Figma、纸面线框或本机网页 | 从开始到复述可走通；无需识字 |
| GLOBAL-02 | 三位旅伴与姿态参考表 | 插画师或图像生成工具 | 人物一致；虚构身份清楚 |
| GLOBAL-03 | 时间河与27个路线站点图形 | 矢量编辑器 | 时间窗口正确；图形与语音对应 |
| GLOBAL-04 | 五步标记与操作图标 | Inkscape等矢量工具 | 符号固定；小尺寸和触控清楚 |
| GLOBAL-05 | 证据身份与图片容器 | 页面设计工具与网页组件 | 原物、后世作品、今景、模拟可区分 |
| GLOBAL-06 | 声音角色与读音规范 | 生成脚本、Audacity | 三类材料试听；锁定速度、停顿与人名年代 |
| GLOBAL-07 | 统一任务、播放器与本机存档组件 | 项目网页工具链 | 暂停续播、选中确认、失败恢复与进度正确 |
| GLOBAL-08 | 任务校验与儿童观察表 | Node检查、页面测试、纸面记录 | 结构、真实行为与儿童理解分别验收 |

## 逐任务工单命名与字段

使用“任务ID／步骤ID／用途”定位工作，例如 `cn-ancient-04-01-qin-unification/beginning/choice-visuals`。这里是制作定位，不要求更改已经稳定的正式素材和声音ID。

每项工单包含：负责人或待分配角色、关联任务和步骤、用途、信息焦点、来源与候选素材、需要新作的部分、尺寸与文件格式、身份与许可、旁白及读音、交付路径、审核结果。负责人未知时留待分配，不杜撰人员或日期。

### 一张主线图的工单

1. 写出孩子在这一步必须观察到什么。
2. 先找本任务资料中的直接证据，确认是否有可用许可和适合的画质。
3. 没有合适证据图时，可以用现有证据重复观察，或制作明确标明的学习示意。
4. 写明不能改变的细节、必须保留的上下文和不能推出的结论。
5. 导出儿童页与家长查看尺寸，保留原图或可编辑源文件。
6. 连同本步故事、问题、选项和声音一起审核。

### 一张选项图的工单

写明选项要表达的完整意思、可听短句、画面对象、人物动作、与其他选项的差别，以及为什么正确或不成立。对错不能由颜色、大小、亮度或画得更漂亮暗示。地图、文学与人物行动要用适合自己的视觉表达，不能机械把长句塞进图里。

### 一段声音的工单

包含稳定ID、用途、当前文字、文字版本、语音角色、读音、语速与停顿、触发位置、前后相邻段落、文件路径和校听人。相同文字与声音参数可复用；文字或参数变化要追踪相关页面。国歌、历史录音和音乐作品先确认可用材料，没有合适材料时用旁白介绍，不用生成声音冒充当日原声。

## 文件与导出建议

| 素材类型 | 编辑源或母版 | 运行输出 | 注意事项 |
| --- | --- | --- | --- |
| 文物与遗址照片 | 原始下载文件与署名说明 | 按显示尺寸生成JPEG或WebP | 不拉伸；低清不放大要求辨字 |
| 图标和学习地图 | SVG或设计源文件 | SVG或透明WebP | 标签与底图分层；时空信息人工核对 |
| 角色与学习插画 | 分层设计稿或高质量PNG | 按页面尺寸生成WebP或PNG | 标为艺术表现或学习示意 |
| 语音 | 原始输出；可用时留无损母版 | 平台支持的MP3等格式 | 核对实际播放、音量、首尾与读音 |
| 动效 | 简短状态说明与可编辑源 | 网页或平台可支持形式 | 有静态替代；不持续抢注意力 |
| 事实与分镜 | Markdown与结构化JSON | 校验后的平台无关内容包 | 不直接手改生成文件 |

图片尺寸由实际显示需求决定。新增主图宜保留足够清晰的源稿，先确定横竖构图再导出，不为统一尺寸裁掉证据。文件大小预算依据当前本机网页的实际加载情况确定，不以手机测试为前提。

## 制作工具的最小组合

本机必要组合是：文本编辑与项目校验脚本、图片或矢量编辑工具、语音样本生成与音频检查工具、网页运行环境与当前浏览器。Figma可用于多人协作，但不作为必须购买或连接的前提。图像生成工具只负责合适的艺术内容；事实、地图、素材身份与许可仍需人工判断。

语音生成可以联网，儿童播放使用准备好的本地文件。生成服务、正式声音参数与后续微信框架在相应阶段确认；本工作单不启动安装、购买、正式批量合成或发布。

## 批量制作时的统计口径

对每个任务分别记录“可直接复用／需调整／需新作／待许可／待审核”，汇总去重后才形成工作量。五步图片位置、选项图形、音频逻辑槽位、实际文件数与最终通过数分别统计。不要用任务完成比例估算素材许可或儿童理解通过比例。

## 移交前检查

- [ ] 素材、声音和内容的ID与任务分镜一致。
- [ ] 页面实际使用的文件存在，图片不失真，音频能在目标播放器正常播完。
- [ ] 来源位置和许可记录完整；仅供研究或编辑的材料不进入儿童页。
- [ ] 每步都能说清为什么选这张图；同一问题修复后回查全库。
- [ ] 语音、触控、重听、暂停、退出、恢复和完成状态有实测记录。
- [ ] 制作产物与审核结果分开，正式批准由实际验收决定。
