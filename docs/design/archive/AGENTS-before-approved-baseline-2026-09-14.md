# 小小历史旅行团协作规范

## 项目目标

这是一个面向4—6岁儿童与家长共学的历史游戏。儿童层以图标、大按钮和预生成语音为主，不假设孩子识字；家长与编辑审核层收在儿童页底部的独立入口。当前阶段先在本机网页版验证内容、图片、语音和玩法；只有内容全部确认后，才转换为微信小程序。

固定原则：

- 中国史采用中国课程标准、统编教材结构和中国权威机构材料作为主体脉络。
- 世界史保持独立时间线，不把中国史写成欧美史附录，也不虚构同期联系。
- 每章先定位时间，再回答一个核心问题，并用真实文物、遗址、档案或清楚标注的艺术表现提供证据。
- 儿童可见文字短而清楚，详细说明优先交给可暂停、重播的本地预生成语音。
- 不要求孩子登录ChatGPT；本机试玩不上传儿童数据。
- `research: verified`、初稿完成或自动校验通过，都不等于最终审核通过。

## 事实来源层级

优先级从高到低：

1. 教育部课程标准、统编教材及其官方教学说明；
2. 中国国家级和省级博物馆、考古研究机构、档案馆、政府与权威党史资料；
3. 其他国家的博物馆、国家图书馆、档案馆、大学馆藏和联合国教科文组织；
4. 开放授权文件页，只用于图片作者、年代、馆藏和许可等元数据；
5. 商业媒体、旅游文章和百科式整理只能帮助发现线索，不直接支撑儿童正文。

事实、推断和故事表达必须分开。文物不能代替真人自述，现代复原不能冒充历史现场，单张图片不能推出人物动机或全国状况。

## 权威文件与生成文件

按以下顺序判断“哪份文件说了算”：

1. `AGENTS.md`：长期产品原则、协作规则与质量门禁；
2. `docs/BUILD-PLAN.md`、`docs/TODO.md`：当前阶段与后续任务；
3. `content/product-map.json`、`content/catalog*.json`：完整范围；`content/preview-scope.json`：当前HTML展示范围；
4. `content/chapters/*.md`：研究事实与编辑背景；`content/focused-quests.json`：当前34章试玩讲述、提问、选项、学习图描述、来源及结束任务。`prepare-focused-quests.mjs` 将其投影至低龄入口、故事拍点和课本连接，修改重点章主线应先改 focused-quests；其余69章仍以原稿与三份入口索引为准；
5. `content/sources.json`、`content/assets/*.json`：来源和素材许可登记；
6. `reference-assets/*/ATTRIBUTION.md`：本地研究素材的署名与证据边界；
7. `public/content/**`、`content/runtime/**`：由脚本生成的运行包，不手工编辑。

进度数字以 [content/PROGRESS.md](content/PROGRESS.md) 和生成后的 `public/content/manifest.json` 为准。资源索引见 [docs/RESOURCES.md](docs/RESOURCES.md)。

## 内容制作流程

1. 先修改章节Markdown或逐题JSON、目录、来源或素材登记；重点章逐题内容必须逐步注明 sourceIds，保持研究事实与试玩表述一致。
2. 每条事实卡在句末直接引用已登记的来源ID。
3. 每章第一屏明确为时间线或时间定位；普通大字块不超过90个汉字，第一屏短节点合计不超过120字。
4. 互动只检验时间、位置、因果和证据，不使用伤亡、抢夺、财富、人群高低、文明排名或阵营胜负得分。
5. 运行 `npm run content:validate:assets`，核对本机研究原图、许可和路径。
6. 运行 `npm run content:pack`，重新生成103章平台无关JSON。
7. 运行 `npm test`、`npm run lint` 和 `git diff --check`。
8. 更新 `content/PROGRESS.md`、`docs/TODO.md`；用户可见里程碑还要更新 `docs/CHANGELOG.md`。

发现系统性问题时必须检查完整103章内容库的结构影响；本轮按用户要求重写34章并隐藏其余69章，隐藏章的同类内容问题继续列入后续建设，不能因隐藏视为已修完。

## 素材规则

- `content/assets/*.json` 是素材身份、来源、许可、用途和边界的正式登记。
- `reference-assets/` 中的原图是本机研究缓存；媒体文件不进入普通Git，署名说明必须提交。
- 页面实际使用的缩略图和运行素材放在 `public/`，并且只能来自已清权素材或明确标注的自制图。
- `clearance` 未确认的素材只能供编辑核对，不进入儿童发布层。
- 低分辨率史料只能作为小型证据卡，不放大要求儿童辨字。
- 资源目录、缓存策略和当前数量见 `docs/RESOURCES.md`。

如果以后需要跨机器同步全部原图，应先引入Git LFS或独立对象存储，不得直接把数百MB研究缓存提交到普通Git历史。

## 语音规则

- 浏览器实时TTS不是正式方案；正式产品使用预先生成的本地音频。
- 本机五步玩法使用 `content/voice-interface-lines.json`、`content/focused-quests.json`、`content/quest-story-paths.json`、`content/textbook-connections.json` 与内容包共同生成界面声音；相同文字只保留一个稳定声音ID，其中逐步图片说明与每一步稳定绑定；重点章人物与文化讲述进入实际步骤，不另行自动堆叠封面介绍；`public/audio/voice-lines.json` 和音频清单均为生成文件，不手工编辑。
- 界面声音必须逐页对齐：章介绍、故事、当前问题、每个选项、对错反馈和结束回答分别使用稳定ID；故事与问题过长时顺序播放两个短段。
- 编辑稿729篇已拆成1154段短音频结构：729段主线、425段“想听更多”，每段不超过90个汉字。
- 正式批量生成前必须先冻结文字、音色、语速、停顿和多音字表。
- A/B试听文件只用于定音，不代表1154段正式结构化音频已经完成。
- `scripts/generate-voices.mjs` 必须先写暂存文件，全部成功后再替换旧音频；断网或合成失败不得损坏已有文件。
- 语音稿修改后必须重新生成内容包并核对稳定ID。

## 本机试玩

- 双击 `本机试玩.command` 启动；说明与儿童观察问题见 `本机试玩说明.md`。
- 当前34章均从“历史站—任务卡—章节封面—五步任务”进入；步骤固定一屏，点图可放大并听说明，结束以两条具体动作进行亲子回应。完整库仍有103章，但不可称103章均已完成本轮内容重做或通过真实儿童测试。
- 本机试玩反馈重点记录：孩子是否能找到开始、是否愿意听完、在哪一步跳过、能否复述因果链、能否分清真实文物和故事角色。

## 平台边界

内容层保持JSON、Markdown和本地媒体，不写入JSX、WXML或微信专有API。登录、学习记录、支付和平台播放器属于界面层。

在用户明确确认内容冻结以前：

- 不转换微信小程序；
- 不接入微信登录或支付；
- 不部署新版本到公网；
- 不批量生成全部正式语音。

## Git规则

- 可以按用户要求生成本地里程碑提交，但不得自动推送。
- 不覆盖、暂存或提交无法确认归属的用户改动。
- 提交前检查暂存清单，避免把本机研究原图、缓存、构建目录和密钥放进Git。
- 提交信息应说明用户可理解的里程碑，例如“完成103章故事弧与逐步配图”。
