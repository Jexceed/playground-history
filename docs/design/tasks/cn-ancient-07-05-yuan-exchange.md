# 035 驿站里来了哪些旅行者

- 任务ID：`cn-ancient-07-05-yuan-exchange`
- 板块与时间：中国古代史／元朝／1271—1368年
- 地点：大都、泉州与欧亚交通网络
- 人物或群体：驿卒、商旅、使者、工匠与学者

## 任务要解决什么

- 核心问题：一匹驿马、一艘海船和一张通行凭证，怎样让消息走得更远？
- 记忆入口：驿站凭证、海船遗物与路线图
- 孩子带走的话：驿站、运河和港口组成许多节点，消息与货物要靠不同人接力。

## 内容组织

1. 先拿一张驿站凭证，跟驿卒换马继续赶路。
2. 接着到泉州港，看海船把人和物带向远方。
3. 最后商旅、使者和学者让欧亚交流更频繁。

表达边界：不让一位著名旅行者代表全部往来，也不从一件外来器物编完整旅程。

## 事实底稿与来源入口

以下是本任务相关事实底稿的查阅起点。其引用沿用正式内容资料，尚不等于每个新分镜都已完成逐句出处定位。编辑应从原稿核对，选择儿童主线必要的说法，并把原文位置填入任务模板。

- 原稿事实1：元朝在水陆交通要道设置驿站，并整治大运河，帮助政令、人员和物资跨地区移动。 [NMC-LIAO-SONG-XIA-JIN-YUAN]
- 原稿事实2：驿站首先服务官方通信和运输，不是所有普通人都能免费使用的现代公共旅馆。 [NMC-LIAO-SONG-XIA-JIN-YUAN]
- 原稿事实5：元代青花瓷等瓷器是生产、审美和贸易的实物证据，瓷器沿陆海路线分布；一只瓷罐不能独自证明具体航线或主人身份。 [NMC-YUAN-PORCELAIN-EXHIBITION]
- 原稿事实7：交流不仅是物品移动，还包括语言、宗教、天文、医学和工艺知识的相互影响。 [NMC-LIAO-SONG-XIA-JIN-YUAN]
