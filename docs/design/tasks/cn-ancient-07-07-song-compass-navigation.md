# 031 小小指南针为什么不能独自开船

设计版本2.0 · 制作草案 · 本卡不是已冻结儿童稿。

- 任务ID：`cn-ancient-07-07-song-compass-navigation`
- 板块与时间：中国古代史／宋朝（与辽·西夏·金并立）／916—1279年（宋960年起）
- 地点：宋代海船、港口与近海航路
- 人物或群体：船长、水手、记录者和掌握航路的人

## 任务要解决什么

- 核心问题：指南针和星辰、风向、水深，怎样一起帮助海船辨认方向？
- 记忆入口：指南浮针与航海工具箱
- 孩子带走的话：指南针给方向，天空、海岸、风向、水深和经验补上其他线索。

## 内容组织

1. 先等磁针稳定下来，找到一条可以核对的方向。
2. 接着观察星辰、太阳、海岸、风向和水深。
3. 最后由船上成年人商量、记录并调整航路。

表达边界：不说有指南针就永远不会迷路；儿童图只作原理示意，不冒充宋代原物。
