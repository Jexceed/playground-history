# 015 一只碗怎样跟着人们去江南

设计版本2.0 · 制作草案 · 本卡不是已冻结儿童稿。

- 任务ID：`cn-ancient-05-01-division-migration`
- 板块与时间：中国古代史／三国两晋南北朝／220—589年
- 地点：洛阳、建康与长江流域
- 人物或群体：迁徙家庭、当地居民和不同政权的普通人

## 任务要解决什么

- 核心问题：道路、行李和日用陶器，怎样留下人们从北方迁往南方的线索？
- 记忆入口：迁徙记录、道路与日用陶器
- 孩子带走的话：战乱和政权变化让许多人分批迁徙；日用器物与记录帮助我们寻找他们重建生活的线索。

## 内容组织

1. 先让一只陶碗跟着搬家的人越过长江。
2. 接着看新来者和原有居民怎样一起生活。
3. 最后器物、道路和记录拼出迁徙后的江南。

表达边界：“跟着一只碗”只是寻找证据的学习线索，不虚构某个家庭的真实经历；不用逃难画面刺激儿童，也不把迁徙说成整齐的一次搬家。
