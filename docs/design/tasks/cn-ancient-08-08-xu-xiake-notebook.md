# 041 徐霞客为什么把每段路写进游记

设计版本2.0 · 制作草案 · 本卡不是已冻结儿童稿。

- 任务ID：`cn-ancient-08-08-xu-xiake-notebook`
- 板块与时间：中国古代史／明朝／1368—1644年
- 地点：江苏江阴及他考察过的山川道路
- 人物或群体：徐霞客、同行帮助者、当地居民与后来的整理者

## 任务要解决什么

- 核心问题：看山、进洞、辨水路再写下日期，怎样帮助徐霞客检查书本里的老答案？
- 记忆入口：旅行日记、路线、洞穴与河流记录
- 孩子带走的话：徐霞客用实地观察和逐日记录积累地理知识；今天的《游记》还经过后人整理。

## 内容组织

1. 先跟徐霞客上路，看山、进洞、辨水路。
2. 接着每天写下日期、路线和亲眼观察。
3. 最后后人整理日记，《游记》保存长期考察。

表达边界：不鼓励儿童独自探洞或模仿危险旅行；后世画像不是生前照片，整理本也不是一次写完的原稿。
