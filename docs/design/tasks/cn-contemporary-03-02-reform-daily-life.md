# 064 一张粮票怎样慢慢退出生活

设计版本2.0 · 制作草案 · 本卡不是已冻结儿童稿。

- 板块与时间：中国现代史／改革开放与中国特色社会主义建设／1978—2012年
- 地点：城市社区、乡村家庭与新市场
- 人物或群体：不同地区、不同家庭的普通人

## 任务要解决什么

- 核心问题：商店、冰箱、电话和出行方式，为什么不会在同一天全部改变？
- 记忆入口：粮票、家用电器、电话与家庭照片
- 孩子带走的话：改革进入日常生活是渐进过程，不同地区和家庭得到新条件的时间不同。

## 内容组织

1. 先拿一张粮票，看看它能换到什么。
2. 接着看市场、电器和电话走进不同家庭。
3. 最后粮票慢慢退出，生活选择越来越多。

表达边界：不比较家庭贫富，不把城市经验当全国同步变化。

## 家长陪伴与可选加餐

给家长的目标：围绕“商店、冰箱、电话和出行方式，为什么不会在同一天全部改变？”，让孩子指一条证据，再说说“改革进入日常生活是渐进过程，不同地区和家庭得到新条件的时间不同。”中的关系。

加餐候选：票证观察员。在粮票上找出“年份、单位、适用范围、印制机构”四类信息，再判断“能证明可购数量”和“不能证明商品售价、家庭收入、全国供给量”；不把粮票做成可交易、抽卡或估价的收藏品。
