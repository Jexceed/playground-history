# 023 骆驼俑里的长安

设计版本2.0 · 制作草案 · 本卡不是已冻结儿童稿。

- 任务ID：`cn-ancient-06-03-tang-changan`
- 板块与时间：中国古代史／唐朝／618—907年
- 地点：唐代长安东市与今天的西安
- 人物或群体：乐手、歌者、商旅与长安工匠

## 任务要解决什么

- 核心问题：道路、市场遗址和骆驼俑怎样帮助我们认识长安的往来？
- 记忆入口：三彩载乐骆驼俑
- 孩子带走的话：骆驼俑、乐舞和市场说明长安连接远方；一座热闹城市靠很多人共同工作。

## 内容组织

1. 先在博物馆观察载乐骆驼俑，认出陶俑中的乐舞形象。
2. 接着看道路与东市遗址，寻找商旅和工匠活动的证据。
3. 最后把不同证据放在一起，认识城市里的交流与合作。

表达边界：陶俑是艺术形象，不是骆驼真的驮整支乐队旅行的照片。 陶俑中的乐队不是一支已被证实骑骆驼走进东市的队伍；虚构旅伴与文物中的人物始终分开。

## 事实底稿与来源入口

以下是本任务相关事实底稿的查阅起点。其引用沿用正式内容资料，尚不等于每个新分镜都已完成逐句出处定位。编辑应从原稿核对，选择儿童主线必要的说法，并把原文位置填入任务模板。

- 原稿事实9：陕西历史博物馆藏“三彩载乐骆驼俑”表现七名男性乐手和一名女性歌者，人物围坐或站立在骆驼背上的平台中。 [SHAANXI-SANCAI-CAMEL-509]
- 原稿事实10：国家博物馆所藏同类载乐骆驼表现舞者、乐手和胡乐器，并把场景与长安百戏联系起来；两件不同馆藏不能拼成同一件文物。 [NMC-SANCAI-MUSIC-CAMEL; NMC-BAIXI-STUDY]
- 原稿事实11：载乐骆驼保存的是艺术形象，不是骆驼真的驮着整支乐队上路的现场记录，也不能据此复原一首确定的“唐代原声”。 [SHAANXI-SANCAI-CAMEL-509; NMC-BAIXI-STUDY]
- 原稿事实12：道路、遗址、人物俑和乐舞俑回答的问题不同：前两者帮助观察空间与城市活动，后两者帮助观察当时艺术中的人物和文化形象。 [UNESCO-CHANGAN-TIANSHAN; CASS-CHANGAN-EAST-MARKET-2015; NMC-WESTERN-RIDER-CAMEL; SHAANXI-SANCAI-CAMEL-509]
