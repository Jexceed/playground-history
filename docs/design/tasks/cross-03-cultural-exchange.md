# 100 骆驼背上的乐队是真的吗

设计版本2.0 · 制作草案 · 本卡不是已冻结儿童稿。

- 板块与时间：跨学科主题学习／跨时代证据任务／贯穿中国史与世界史
- 地点：西安、长安交流网络与伊朗尼沙普尔
- 人物或群体：乐手、歌者、陶工、商旅与考古人员

## 任务要解决什么

- 核心问题：一件唐三彩、一个远方器形和一块出土残片，怎样一起证明交流？
- 记忆入口：三彩载乐骆驼俑与尼沙普尔陶片
- 孩子带走的话：三件实物放回时间与地点，能证明工艺和器物经过许多人接力传播。

## 内容组织

1. 先看三彩骆驼背上的乐手和釉色。
2. 接着对照远方陶片、器形和出土地点。
3. 最后三件实物互相支持，说明工艺经过多人传播。

表达边界：艺术场景不是商队照片；能看见乐器，不能复原确定的唐代原声。
