# 008 一只量杯怎样帮秦国改规则

设计版本2.0 · 制作草案 · 本卡不是已冻结儿童稿。

- 任务ID：`cn-ancient-03-02-reforms-unification`
- 板块与时间：中国古代史／春秋战国／前770—前221年
- 地点：战国秦国与今天的陕西、河南一带
- 人物或群体：商鞅、秦孝公和执行新规则的人

## 任务要解决什么

- 核心问题：量杯上的小字，能告诉我们商鞅变法改变了什么吗？
- 记忆入口：商鞅方升
- 孩子带走的话：统一量器只是一个窗口；新法律、奖惩和基层组织一起改变了秦国。

## 内容组织

1. 先拿商鞅方升量一量，看各处是否用同一标准。
2. 接着看新规则怎样让办事和奖惩更统一。
3. 最后发现量杯虽小，背后是秦国在改规则。

表达边界：不把战争胜负做成得分，也不把变法成败归给单一人物。

## 事实底稿与来源入口

以下是本任务相关事实底稿的查阅起点。其引用沿用正式内容资料，尚不等于每个新分镜都已完成逐句出处定位。编辑应从原稿核对，选择儿童主线必要的说法，并把原文位置填入任务模板。

- 原稿事实3：变法不是秦国独有，战国多个诸侯国都曾通过改变制度来加强统治和竞争能力。商鞅在秦孝公支持下推行的变法，是其中的重要一例。 [NMC-SPRING-AUTUMN-WARRING-STATES; SHM-SHANGYANG-MEASURE]
- 原稿事实4：商鞅方升铸造于秦孝公十八年，即公元前 344 年，容积实测约 202.15 立方厘米。第一组铭文记录“大良造鞅”制定一升的标准，是商鞅变法和统一度量衡的重要实物证据。 [SHM-SHANGYANG-MEASURE]
- 原稿事实5：方升底部和另一侧还有秦王政二十六年，即公元前 221 年统一后加刻的第二组诏书。两组铭文相隔一百多年，不能把后刻内容误当作商鞅当年铭文。 [SHM-SHANGYANG-MEASURE]
- 原稿事实6：战国各地商业发展，不同诸侯国铸造形制不同的货币，并使用不同的度量标准。这能帮助孩子理解后来统一制度面对的现实问题。 [NMC-SPRING-AUTUMN-WARRING-STATES; SHM-SHANGYANG-MEASURE]
