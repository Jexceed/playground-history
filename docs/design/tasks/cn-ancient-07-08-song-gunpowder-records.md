# 032 火药知识怎样被安全记进书里

设计版本2.0 · 制作草案 · 本卡不是已冻结儿童稿。

- 任务ID：`cn-ancient-07-08-song-gunpowder-records`
- 板块与时间：中国古代史／宋朝（与辽·西夏·金并立）／916—1279年（宋960年起）
- 地点：北宋书房、开封与不同使用场景
- 人物或群体：曾公亮等编书者、记录者与后来的使用者

## 任务要解决什么

- 核心问题：长期观察怎样变成书中记录，再发展出不同用途？
- 记忆入口：《武经总要》传世图像与安全记录示意
- 孩子带走的话：长期观察留下记录，书籍帮助传播，后来的人又在不同场景中改进和使用。

## 内容组织

1. 先看古人怎样把材料和现象分开观察、记录。
2. 接着看《武经总要》怎样把知识传给后来的人。
3. 最后比较节庆、信号和军事用途的作用与风险。

表达边界：儿童层不呈现配方、比例、混合、点火或武器操作，只学习证据、年代与用途变化。
