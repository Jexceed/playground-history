## 二、每章八项验收

每项只能填写“通过”“修改后再看”或“不适用”，不能用“差不多”。

| 验收项 | 通过标准 | 结果 |
| --- | --- | --- |
| 1. 时间定位 | 第一屏先说清时间、地点和前一章留下的问题；孩子知道故事发生在什么时候 |  |
| 2. 前后脉络 | 每个事件都有上一步原因和下一步影响；没有只靠年份堆叠的跳跃 |  |
| 3. 事实准确 | 所有关键句能在句末来源编号中找到直接支持；事实、推断、创意表达分开 |  |
| 4. 低龄文字 | 大字短句清楚，首次出现的抽象词有口语解释；一屏只承担一个核心意思 |  |
| 5. 语音稿 | 朗读自然，句子不绕；语音补充解释而不是逐字重复屏幕；听完能复述一件事 |  |
| 6. 真实素材 | 图片来自真实文物、遗址、档案或已标明的艺术表现；复制品、复原图、现代照片都有显著标签 |  |
| 7. 互动价值 | 操作检验时间、位置、因果或证据；不靠战争伤亡、抢夺、财富或人群高低得分 |  |
| 8. 儿童复述 | 孩子能用自己的话回答“什么时候”“发生了什么”“我们凭什么知道”三个问题 |  |

## 三、素材逐张抽查

1. 打开素材登记中的本地图片，确认文件能正常显示、没有拉伸、没有难以辨认的小字。
2. 对照 `sourcePage` 和 `licenseUrl`，确认题名、作者、年代、馆藏机构和许可一致。
3. 检查图片下方的儿童标签：至少明确“真实文物/历史档案/遗址今景/艺术表现/现代复原/路线示意”之一。
4. 图片只能支持它实际显示的内容。人物表情不推断立场，单张照片不代表全国，路线图不冒充古人原图。
5. 两项未清权素材只供编辑核对，不出现在发布包；低分辨率史料只作小型证据卡，不放大识字。

## 四、语音确认顺序

1. 先确认十二个代表章的文字和语音稿，不在内容仍可能改动时批量合成。
2. 已从本地合成方案生成两组试听：A组温和讲述，B组稍有角色感；两组都用同样的时间线、文物解释和复杂因果材料比较，试听入口位于网页“查看完整91章”顶部。
3. 用三段不同难度材料试听：时间线、文物解释、复杂因果。确认音色、速度、停顿和多音字后锁定参数。
4. 653段编辑语音稿目前拆成1092段低龄短音频，每段不超过90个汉字：每篇第一段为主线，共653段；其余439段为“想听更多”。确认文字后按短音频编号批量合成；每段保存章节、屏幕、语音稿、短段号、层级、文字版本和声音参数，网页与后续微信小程序共用同一套文件。
5. 抽听片头、片中、片尾和含年代/人名/地名的段落；发现系统性读音问题时重新生成同类片段。
