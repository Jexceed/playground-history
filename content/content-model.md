# 跨平台内容模型

## 选择

历史内容采用纯 JSON + Markdown + 本地媒体文件，不写进 React 组件，也不依赖微信小程序专有格式。

这套结构可以同时被以下界面读取：

- 当前 Next.js 网页版；
- 后续微信小程序原生页面；
- 未来可能的平板应用、教师端或内容管理工具。

## 稳定边界

### 内容层负责

- 时间、地点、人物、事件和前后因果；
- 儿童正文与语音稿；
- 地图、遗址、文物、文献等证据；
- 互动题、答案与解释；
- 事实来源和图片授权；
- 每章在总时间线中的位置以及同期世界连接。
- 每章儿童卡片首先出现的具体问题、物件、人物或群体、地点与文化连接，以及低龄展示边界。

### 界面层负责

- 卡片、按钮、转场和动画；
- 横屏或竖屏布局；
- 网页、微信和其他平台的音频播放器；
- 登录、学习记录、会员和支付。

内容文件中不写 JSX、WXML、HTML 片段和平台 API。

## 文件组织

```text
content/
  timeline.json              中国历史八段主时间线
  product-map.json           中国史、世界史完整产品范围
  catalog.json               已拆分到章节级的目录
  child-entry-points.json    91章面向4—6岁的物件/人物/地点/文化入口与短回答
  child-language-glossary.json  76个抽象词的儿童口语解释
  voice-pronunciations.json  配音前人名/地名/多音字与年代读法基线
  sources.json               可机器读取的事实来源登记
  chapters/                  每章研究稿、儿童稿和语音稿
  assets/                    每章素材与授权状态
  schema/                    数据格式说明
reference-assets/            已下载的开放授权原图
public/content/              页面正式使用时生成的发布副本
public/audio/                正式语音文件
```

## 稳定 ID

- 时期：`sui-tang-five-dynasties`
- 章节：`cn-ancient-06-03-tang-changan`
- 内容屏：`cn-ancient-06-03-evidence-market`
- 素材：`tang-sancai-music-camel-front`
- 来源：`NMC-SANCAI-MUSIC-CAMEL`

ID 一旦进入正式版本就不再改名，网页版和微信端才能共享学习进度。

## 单章完成标准

一章只有同时满足以下条件，状态才能改为 `approved`：

1. 有清楚的前因、本章问题和后续影响。
2. 正文中的每一个可核查事实都能指向 `sources.json` 中的来源。
3. 至少使用两种证据类型，如遗址 + 文物，不能只靠讲故事。
4. 普通儿童大字块不超过90个汉字；第一屏时间线可由多个短节点组成，总计不超过120字。语音使用独立台词 ID，复杂总览可拆成主讲与证据提醒，并支持暂停、重播。
5. 互动题检查观察、排序、因果或证据判断，不只考人名和年份。
6. 图片有明确的来源、作者和许可；授权不清的图片只作研究参考。
7. 虚构情节明确标注为故事层，不能伪装成史实。
8. 由另一轮事实审核检查时间、称谓、因果和地图范围。

## 同期世界连接

中国史是主叙事。世界史连接只回答“同一时期，别处发生了什么，以及双方是否真的发生联系”，不把中国史变成西方史的附录，也不把没有证据的两个事件强行建立因果。
