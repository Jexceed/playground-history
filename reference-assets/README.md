# 本机研究素材缓存

这个目录保存历史游戏的原始研究图片、PDF、SVG和少量视频。媒体文件约708.5MiB，只在本机保留，不进入普通Git历史。

当前共有428个媒体文件，其中417个唯一路径被素材登记直接引用，另外11个是辅助研究文件或替代格式；严格路径检查为417/417。

会进入Git的文件：

- 本说明；
- 每个主题目录中的 `ATTRIBUTION.md`，用于记录素材题名、作者、年代、来源、许可和证据边界。

正式素材身份与使用许可仍以 `content/assets/*.json` 为准。网页运行时使用 `public/` 中已清权并生成的素材，不直接读取本目录。

本机缓存完整性检查：

```text
npm run content:validate:assets
```

不要把缺失的本机缓存自动解释为许可失效；应先按素材登记中的 `sourcePage` 和 `licenseUrl` 恢复原文件并重新核对。未来若要同步全部原图，先配置Git LFS或独立对象存储。
