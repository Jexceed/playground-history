# 小小历史旅行团品牌标识

当前使用：`history-trip-logo-v3.png`。内置image_gen生成白底源图`history-trip-logo-v3-white-source.png`，以原生CoreGraphics规范透明圆角边界后导出；人物、地图与长城由生成图保留，没有用代码重画。按OpenAI使用条款持有输出使用权。

概念：三位固定小伙伴共同拿着地图，地图上保留蓝色时间河，长城作为中国历史线索。2026-10-10用户认可居中聚合的App图标构图并授权替换，依后续反馈将浅薄荷底板改为白色，取消厚金边与复杂远景。角色、色彩与画风参考已登记的主页`homepage-history-travel-river-v4-illustration`。黄衣翘发男孩、红衣高马尾女孩和绿衣圆框眼镜男孩分别保留各自特征。

它是虚构的品牌图形，不是地理地图、特定朝代的长城复原、文物或史料。当前提示词、导出脚本和源文件校验见`docs/qa/2026-10-10-logo-white/`，候选构图过程见`docs/qa/2026-10-10-logo-candidate/`。PNG派生版本用于共享品牌入口与Mac ICNS；源图不进入普通Git，运行派生图随代码分发。

旧版`history-trip-logo-v1.png`（书页、拱桥与时间河）、`history-trip-logo-v2.png`（金框场景版）、v2初稿与v3候选均保留供追溯。v1提示词与校验仍在`docs/qa/2026-10-08-macos-app/`，v2记录在`docs/qa/2026-10-09-logo-refinement/`。旧版不再用于当前入口。
